COMPUTER ARCHITECTURE · ERROR CONTROL CODES

Hamming Code

Hamming code adds carefully chosen redundant bits so that a receiver can not only detect a single-bit error, but also identify exactly which bit position is wrong and correct it. This lesson follows the notation used in the referenced Neso Academy example: the three redundant bits are named P1, P2 and P3. P3 is the third parity bit and is physically placed at code-word position 4.

Data→Add redundant bits→Transmit→Check P1, P2, P3→Form error position→Correct
01 · WHY HAMMING CODE?

Ordinary parity can detect an error, but cannot tell us where it occurred.

Suppose a sender transmits a binary word and one bit changes because of noise. A simple parity bit can tell the receiver that the total parity is no longer correct. But it cannot answer the more important question: which particular bit changed?

Hamming code solves this by adding more than one parity bit. Each parity bit watches a different group of positions. The groups overlap in such a way that every bit position has a unique combination of parity checks. At the receiver, the results of those checks behave like an address pointing directly to the faulty bit.

Mental picture: imagine three security cameras watching different sets of seats in a classroom. If only Camera 3 reports a problem, the combination of reports can point to one specific seat. Hamming code uses parity groups in the same way.
02 · HOW MANY REDUNDANT BITS?

Use 2r ≥ m + r + 1.

Let m be the number of original data bits and r be the number of redundant or parity bits. We need enough parity-result combinations to represent every possible erroneous bit position and one additional combination for “no error”.

2r ≥ m + r + 1

For 4 data bits

If r=2, then 2²=4, while 4+2+1=7. Four states are not enough.

If r=3, then 2³=8, while 4+3+1=8. The condition is satisfied.

Therefore, 4 data bits need 3 redundant bits. The final code word has 7 bits.

04 · WHICH POSITIONS DOES EACH PARITY BIT CHECK?

Each parity bit checks a repeating pattern of positions.

P1

P1 checks positions 1, 3, 5, 7.

These are exactly the positions whose binary location ends in 1: 001, 011, 101, 111.

P2

P2 checks positions 2, 3, 6, 7.

These positions have the 2's-place bit equal to 1: 010, 011, 110, 111.

P3

P3 checks positions 4, 5, 6, 7.

These positions have the 4's-place bit equal to 1: 100, 101, 110, 111.

Notice the overlap. Position 7 is checked by P1, P2 and P3. Position 5 is checked by P1 and P3. Position 4 is checked only by P3. This unique pattern is what allows the receiver to locate an error.
05 · COMPLETE ENCODING EXAMPLE

Encode data 1001 using even parity.

We have four information bits: 1 0 0 1. The 7-bit Hamming arrangement is:

P1   P2   D1   P3   D2   D3   D4

Now place the data bits 1,0,0,1 into D1,D2,D3,D4:

1P1
2P2
3 = D11
4P3
5 = D20
6 = D30
7 = D41

Step 1 — Find P1

P1 checks positions 1, 3, 5 and 7. Ignore P1 temporarily and look at the known data bits: position 3=1, position 5=0, position 7=1.

There are two 1s. Two is already even, so we must place P1=0 to keep even parity.

P1 group: 0, 1, 0, 1 → two 1s → even ✓

Step 2 — Find P2

P2 checks positions 2, 3, 6 and 7. The known bits are position 3=1, position 6=0, position 7=1.

Again there are two 1s. Therefore P2=0.

P2 group: 0, 1, 0, 1 → two 1s → even ✓

Step 3 — Find P3

P3 checks positions 4, 5, 6 and 7. The known data bits are position 5=0, position 6=0, position 7=1.

There is currently one 1, which is odd. To make the total number of 1s even, we choose P3=1.

P3 group: 1, 0, 0, 1 → two 1s → even ✓
Final Hamming code: 0 0 1 1 0 0 1   =   0011001
06 · WHAT DOES THE RECEIVER DO?

The receiver checks the same three groups again.

At the receiver, we do not immediately remove P1, P2 and P3. First, the receiver checks the parity of the same groups. For even parity:

check result 0 means that parity group is correct. check result 1 means that parity group has failed.

Write the check results in the order P3 P2 P1. This three-bit result gives the binary number of the erroneous position.

Error position = (P3-check   P2-check   P1-check)2

For example, if the receiver obtains 100, then 100₂ = 4. Therefore the error is at position 4.

07 · RECEIVER-SIDE ERROR DETECTION

Let position 4 change during transmission.

The correct Hamming word is 0011001. Position 4 contains 1. Suppose transmission noise changes only position 4 from 1 to 0.

The receiver therefore receives 0010001:

Position 50

Position 71

Receiver checks P1: positions 1, 3, 5, 7

Values are 0, 1, 0, 1. There are two 1s, which is even. Therefore the P1 check passes.

P1 check = 0

Receiver checks P2: positions 2, 3, 6, 7

Values are 0, 1, 0, 1. Again there are two 1s, so the P2 check passes.

P2 check = 0

Receiver checks P3: positions 4, 5, 6, 7

Values are 0, 0, 0, 1. There is one 1, which is odd. Even parity fails for this group.

P3 check = 1
Syndrome / error position = P3 P2 P1 = 100₂ = 4
Therefore the receiver identifies position 4 as the erroneous bit.
08 · CORRECTING THE ERROR

Once the position is known, correction is just one bit flip.

The syndrome says the wrong bit is at position 4. The received value at position 4 is 0, so the receiver changes it back to 1.

Received 0010001→Syndrome 100→Error at position 4→Flip bit 4→Corrected 0011001

After correction, remove the parity positions 1, 2 and 4. The remaining data positions are 3, 5, 6 and 7:

Position 3,5,6,7 → 1 0 0 1 → original data = 1001
09 · COMPLETE ALGORITHM OF HAMMING CODE

Sender + receiver procedure

1

Count the data bits.

Let m be the number of original information bits.

2

Find the number of redundant bits.

Choose the smallest r that satisfies 2r ≥ m+r+1.

3

Construct the final positions.

The code word will contain m+r positions.

4

Reserve power-of-two positions.

Positions 1,2,4,8,… are reserved for parity bits. In the video-style naming used here, the first three are called P1, P2 and P3.

5

Insert data bits.

Put the original information bits into all remaining non-power-of-two positions.

6

Determine P1.

Check positions 1,3,5,7,… and choose P1 so that the required parity condition is satisfied.

7

Determine P2.

Check positions 2,3,6,7,… and choose P2 accordingly.

8

Determine P3.

P3 is physically at position 4 and checks positions 4,5,6,7,… . Choose it so that parity is satisfied.

9

Transmit the complete Hamming word.

Send both the original data bits and the newly calculated parity bits.

10

Receiver repeats all parity checks.

Generate one check result for P1, one for P2 and one for P3.

11

Form the error-position number.

Arrange the results as P3 P2 P1. 000 means no single-bit error. Any non-zero binary value gives the erroneous bit position.

12

Correct and recover the data.

Flip the identified bit, then remove the parity positions to obtain the original data.
