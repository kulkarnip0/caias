01 · WHAT IS K-MAP?

A pictorial way to simplify Boolean expressions

A Karnaugh Map, or K-map, is a visual method for simplifying Boolean expressions. Instead of repeatedly applying Boolean identities line by line, we place the required output values into a carefully arranged grid and combine adjacent cells.

Boolean function→Place values in K-map→Make largest valid groups→Read simplified expression

Boolean-algebra route

Start with a long expression and repeatedly apply identities, distributive laws, complement laws and absorption rules until the expression becomes smaller.

K-map route

Represent the same information as cells. Adjacent cells reveal which variables change and which remain constant. The changing variables disappear from the simplified term.

Why K-map works: neighboring cells are arranged so that they differ in only one variable. When that changing variable appears once as 0 and once as 1, the two possibilities combine and the variable is eliminated.
02 · HOW MANY CELLS?

The number of cells is determined by the number of variables

If a Boolean function has n variables, there are \(2^n\) possible input combinations. Therefore the K-map must also contain \(2^n\) cells—one cell for every possible combination.

2 variables

2² = 4 cells

3 variables

2³ = 8 cells

4 variables

2⁴ = 16 cells

04 · BASIC GROUPING RULES

Before solving questions, learn what a valid group looks like

✓ Horizontal grouping
Adjacent cells in the same row may form a group.
✓ Vertical grouping
Adjacent cells in the same column may form a group.
✗ Diagonal grouping
Diagonal cells are not considered adjacent in a K-map.
✓ Overlap is allowed
A 1 may belong to more than one group when overlap helps produce larger useful groups.

Try the rule

Make the group as large as possible

If four adjacent 1s can be grouped as a quad, do not unnecessarily break them into two separate pairs. Larger groups remove more variables and normally produce a simpler expression.

1 cell→Pair = 2→Quad = 4→Octet = 8
Valid group sizes: 1, 2, 4, 8, 16, ... = powers of 2
Why powers of two? A group represents all possible values of one or more changing binary variables. One changing variable gives 2 combinations, two changing variables give 4, three give 8, and so on.

06 · QUAD AND LARGER GROUPS

Four adjacent cells can eliminate two variables

A quad contains four adjacent 1s. If two variables change through all their combinations while the remaining variable stays fixed, the changing variables are eliminated.

Rule of thumb

Pair → removes 1 variableQuad → removes 2 variablesOctet → removes 3 variables

Suppose four cells all have A=0, while B and C take 00, 01, 11 and 10. Then B and C change, but A never changes. The whole quad simplifies to A′.
Priority: If an octet is possible, prefer the octet. If no octet is possible, look for quads. If no quad is possible, then use pairs. Use single cells only when necessary.

09 · 4-VARIABLE K-MAP

A 4 × 4 map with sixteen minterm positions

For variables A, B, C and D, both the row labels AB and column labels CD use Gray-code order 00, 01, 11, 10.

Click any cell to see its minterm number, binary code and product term.
Remember the edges: top and bottom rows are adjacent, and left and right columns are adjacent. A K-map behaves as if its opposite edges wrap around. Corners can therefore form a valid group of four.

Complete solving strategy

Plot all 1s from the minterm list.
Look first for octets, then quads, then pairs, then isolated 1s.
Use overlap when it helps cover all 1s with larger groups.
For each group, write the binary values of its cells if necessary.
Cancel variables that change between 0 and 1.
If a remaining variable is always 1, write it normally; if it is always 0, write its complement.
Join the terms from all groups using OR (+).
10 · PRACTICE

Check whether the idea is clear

1. How many cells are required for a 4-variable K-map?
16 cells. A function of n variables needs \(2^n\) cells, so \(2^4=16\).
2. Can two diagonal 1s form a pair?
No. Valid K-map adjacency is horizontal or vertical, including wrap-around edges, not diagonal.
3. If a quad is possible, should you split it into two pairs?
Normally no. Use the largest possible group because a quad eliminates two changing variables, while a pair eliminates only one.
4. Why is Gray-code ordering used?
So adjacent cells differ in only one bit. This makes one-variable cancellation possible when neighboring cells are grouped.
5. Simplify the pair A′B′ + A′B.
A′. Factor A′: A′(B′+B)=A′·1=A′.
