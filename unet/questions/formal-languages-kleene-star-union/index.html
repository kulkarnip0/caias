TOC-006 · Theory of Computation · Formal Languages

Empty language, Kleene star, union and concatenation

The question

Consider the languages L₁ = ∅ (phi, the empty language) and L₂ = {1}. Which option represents the language:

L₁* ∪ L₂* L₁*
1) {ε}
2) {ε, 1}
3) ∅
4) 1*

Notation note: The typed expression contains repeated star symbols; this solution interprets it as L₁* ∪ L₂*L₁*, with ∪ meaning union and adjacent languages meaning concatenation.

Step 1: What is a language?

Think of a language as a box containing strings. A string is a sequence of symbols. For example, 1, 11 and 111 are strings made from the symbol 1.

{1} is a language containing exactly one string: 1. It does not automatically contain 11 or 111.

Step 2: What do ∅ and ε mean?

∅ means an empty box: a language containing no strings at all. ε (epsilon) means an empty string: a string with zero symbols.

They are different: ∅ ≠ {ε}. The first box has nothing in it. The second box has one thing in it—the empty string.

Imagine an empty lunchbox: that is ∅. Now imagine a lunchbox holding one empty piece of paper: that represents {ε}. There is one item, but nothing is written on it.

Step 3: What does the star (*) mean?

The Kleene star means we can join together zero, one, two, three, ... strings from a language. Zero repetitions are always allowed, and zero repetitions produce ε.

For L₁ = ∅, there is nothing available to repeat. We can still choose zero repetitions, so:

L₁* = ∅* = {ε}

For L₂ = {1}, repeating 1 gives ε (zero times), 1 (once), 11 (twice), 111 (three times), and so on:

L₂* = {1}* = {ε, 1, 11, 111, ...} = 1*

Step 4: What does putting languages together mean?

Writing AB for languages A and B means concatenation: take one string from A, take one from B, and join them in order.

Because ε has no symbols, joining ε changes nothing: 1ε = 1, 11ε = 11, and εε = ε.

Therefore:

L₂* L₁* = 1* {ε} = 1*

Step 5: What does ∪ mean?

The union symbol ∪ means combine all strings from both languages, without duplicates. Since ε is already included in 1*, adding {ε} does not change it.

L₁* ∪ L₂* L₁* = {ε} ∪ 1* = 1*

Correct answer: Option 4 — 1*

1* = {ε, 1, 11, 111, 1111, ...}

Why not option 2? Because the star does not stop after one repetition. It also allows 11, 111, 1111 and every longer string of 1s.

Very important exam shortcuts

∅* = {ε} because zero repetitions are allowed.

{ε}* = {ε} because repeating an empty string still gives an empty string.

A{ε} = {ε}A = A for any language A.

A ∪ {ε} = A only when ε is already in A.

Try it yourself

If L = {a}, what is L*? Answer: {ε, a, aa, aaa, ...}.

If L = ∅, what is L+? Answer: ∅. Unlike the star, the plus requires at least one repetition.

If L = {ε}, what is L*? Answer: {ε}.
