COMPUTER ARCHITECTURE · UNIT I · BINARY CODES

How does a computer understand our information?

A letter, number, image or audio file must ultimately be represented by patterns of 0s and 1s before a digital computer can store, process or transmit it. Converting information into such patterns is encoding; interpreting the stored pattern again is decoding. Binary codes provide the agreed rules that make both possible.

Information→Encoding→Binary pattern→Storage / transmission→Decoding→Information
01 · WHAT IS A CODE?

A code gives meaning to a pattern of symbols.

When numbers, alphabets or words are represented by a specific group of symbols, they are encoded. The group of symbols used for the representation is called a code. In digital systems the symbols are binary digits, so a group of bits used to represent information is called a binary code.

04 · WEIGHTED CODES & BCD

Each bit position has an assigned weight.

In 8421 BCD, each decimal digit is represented separately using weights 8,4,2,1. Example: decimal 59 becomes 0101 1001. Pure binary 59 is different: 0011 1011.

05 · BCD ADDITION & SUBTRACTION

BCD arithmetic needs decimal-digit correction.

If a 4-bit BCD sum is greater than 1001 or produces a carry, add 0110. Example: 7+8 gives 1111; adding 0110 gives 1 0101 = BCD 15.

9's complement subtraction

If an end carry occurs, discard it and add 1 to the remaining result. If no carry occurs, take the 9's complement and attach a minus sign.

10's complement subtraction

If an end carry occurs, discard it. If no carry occurs, take the 10's complement and attach a minus sign.

07 · GRAY CODE

Consecutive values differ in exactly one bit.

Gray is a non-weighted unit-distance code. The one-bit-change property reduces ambiguity in physical position encoders.

09 · ALPHANUMERIC CODES

Binary patterns represent characters too.

Standard ASCII uses 7 bits: A–Z are 65–90, a–z are 97–122, and character digits 0–9 are 48–57. Example: A=65=1000001. EBCDIC uses 8 bits; Hollerith is a historical character code.

10 · PARITY & HAMMING

Error detection and correction add redundancy.

Parity adds one bit so the total number of 1s is even or odd. It detects every single-bit error but cannot locate the wrong bit. Hamming uses several parity bits at positions 1,2,4,8,…; their check results form a syndrome that can identify a single-bit error. Extended Hamming adds overall parity for SECDED.
