Why does this program print 64?

Question

#include <stdio.h>
int main()
{
    int a = 320;
    char *ptr;
    ptr = (char*) &a;
    printf("%d", *ptr);
    return 0;
}

Options: A) 2    B) 320    C) 64    D) Compilation error

C ProgrammingPointersBits & BytesType CastingLittle Endian

Mental picture first

Core idea: a occupies several bytes. ptr points to the same starting address, but because it is a char*, *ptr reads only the first byte. On a little-endian machine, that first byte of 320 is 64.

1. How many bits are we talking about?

char

1 byte = 8 bits

A char* dereference reads one byte.

int

4 bytes = 32 bits

This is the common 32-bit int model assumed by the question.

int a = 320; [ 8 bits ][ 8 bits ][ 8 bits ][ 8 bits ] total = 32 bits

2. Write 320 using powers of two

Start with the decimal number 320:

320 = 256 + 64

Now express those two numbers as powers of two:

256 = 2⁸ 64 = 2⁶ 320 = 2⁸ + 2⁶

So only bit positions 8 and 6 are switched on.

4. The easiest reason for the number 64: divide 320 into 256-byte chunks

One byte has 8 bits, so one byte can represent 256 different patterns:

00000000₂ = 0 ... 11111111₂ = 255

Therefore, when a larger integer is split into bytes, the lowest byte contains the remainder after division by 256.

320 = 1 × 256 + 64
Higher byte
1

The quotient is 1.

Lowest byte
64

The remainder is 64.

320 % 256 = 64
This is the cleanest numerical explanation: the lowest 8 bits of 320 store the remainder 64.

So 0x40, 01000000₂, and decimal 64 are simply three ways of writing the same 8-bit value.

7. What does &a mean?

Suppose a begins at memory address 1000:

address 1000 → 0x40 address 1001 → 0x01 address 1002 → 0x00 address 1003 → 0x00
&a = 1000

&a means: “give me the starting address of the integer a.”

9. Why does *ptr read only the first byte?

Because ptr is a char*. Dereferencing a pointer reads one object of the pointed-to type.

10. Follow the exact chain to 64

a = 320 320 = 1×256 + 64 lowest byte = 320 % 256 = 64 = 01000000₂ = 0x40 little-endian puts this byte first ptr = (char*)&a ptr points to that first byte *ptr = 01000000₂ = 64
Therefore printf("%d", *ptr) prints 64.

11. One picture to remember

a = 320 320 = 256 + 64 32-bit representation: 00000000 00000000 00000001 01000000 little-endian memory: [01000000] [00000001] [00000000] [00000000] ↑ ptr char* reads one byte 01000000₂ = 64
Exam assumption: 64 is the intended answer for a system with 8-bit bytes, a 32-bit int, and little-endian byte order. C itself does not require this exact representation on every machine.
