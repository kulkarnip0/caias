1. What is a CPU?

A CPU (Central Processing Unit) is the part of the computer that carries out instructions. An instruction is a small command such as load a value, add two numbers, or store a result. A program is a sequence of these instructions.

Imagine a kitchen: a recipe is a program, each recipe step is an instruction, the chef is the CPU, the pantry is memory, and the chef's small work bowls are registers. The chef needs both an order of steps and a signal for when to perform each step.

Memory

Stores instructions and data. Each location has an address, like a numbered box on a shelf.

Registers

Very small, fast storage locations inside the CPU. They hold values currently being used.

ALU

The Arithmetic Logic Unit performs operations such as addition, subtraction and comparisons.

Control unit

Directs the sequence of operations by activating the right control signals at the right time.

Computer Registers — tiny storage inside the CPU

WHAT is a register?

Think of main memory as a large cupboard with many numbered drawers. The CPU is a worker that reads instructions and processes data. A register is a very small, fast storage place inside the CPU, like a small tray on the worker's desk. A register holds a binary number — a sequence of zeros and ones — while an operation is being performed.

WHY are there different registers?

Different jobs need different information. The CPU must remember where to read from, what instruction to perform, which data it is working with, and where the result should go. The registers in the Basic Computer model are assigned specific roles so these values do not get confused.

Important: These are the registers of the educational Basic Computer architecture. Its memory has 4096 addressable words (2¹²), each 16 bits wide. Actual CPUs can have different register names, sizes and designs.

What does 8, 12 or 16 bits mean?

A bit is one binary digit, either 0 or 1. An 8-bit register has eight positions, a 12-bit register has twelve, and a 16-bit register has sixteen. Each additional bit doubles the number of different patterns that can be stored. Thus 8 bits give 256 patterns, 12 bits give 4096 patterns, and 16 bits give 65,536 patterns.

In this model, AR and PC are 12 bits because a 12-bit address can select one of 4096 memory locations. DR, AC, IR and TR are 16 bits because they work with the computer's 16-bit data or instruction words. INPR and OUTR are 8 bits because they handle 8-bit input/output characters or data.

Why the registers cannot be mixed up

PC versus AR: PC remembers the address of the next instruction. AR holds the memory address currently being accessed. They may contain the same value during a fetch, but they serve different purposes.

IR versus DR: IR holds an instruction code, while DR holds a data operand. Both are 16 bits in this model, but their meanings differ.

AC versus TR: AC is the main working register for arithmetic and logic. TR is used when an intermediate value needs to be stored temporarily.

INPR versus OUTR: INPR receives data from an input device, while OUTR holds data to be sent to an output device. Both are 8 bits.

Remember: A register's width tells us how many bits it can store; its function tells us what those bits mean in the CPU.

2. What are timing and control?

WHAT: timing

Timing means deciding when an operation happens. Computers use a clock signal that repeatedly changes between low and high levels. The clock provides a shared rhythm for many CPU activities. A clock cycle is one complete period of that repeating signal.

WHY: control

Control means deciding what happens during each step. A control signal might tell a register to load a value, tell memory to read, or tell the ALU to add. Without control, components would not know which operation to perform.

Simple example: At one step, copy the Program Counter (PC) into the Memory Address Register (MAR). At the next step, read memory. Then copy the fetched instruction into the Instruction Register (IR). The steps must occur in the correct order.

Each labelled step T₀, T₁, T₂, ... is a logical time step in our simplified teaching model. Real CPUs may use pipelining, overlapping stages, and different clocking arrangements. The simulator below deliberately shows one micro-operation at a time.

Hardwired vs microprogrammed control

Hardwired control generates control signals through fixed digital logic. It can be fast, but changing the control logic may be difficult. Microprogrammed control stores sequences of smaller control instructions in control memory. It can make complex instruction control easier to organize, though implementations differ in speed and flexibility.

Timing waveforms and hardwired control — explained

The following two diagrams redraw the ideas in the supplied reference illustrations using large labels. First follow the timing lines; then see how instruction bits and the sequence counter produce control signals.

Understanding the timing-signal diagram (T₀ to T₄)

Imagine a clock that says now do step 0, then now do step 1, and so on. A sequence counter (SC) keeps track of the current step. A 4-to-16 decoder turns its binary number into one active timing line: T₀, T₁, T₂, …, T₁₅.

Each horizontal line below is a separate electrical signal. A high level means the signal is active; a low level means it is inactive. Vertical guide lines mark successive clock intervals. Only one of T₀ through T₄ is shown high at a time in this simplified example.

Read it slowly: During the first interval, T₀ is high. In the next interval, T₀ becomes low and T₁ becomes high. The same happens for T₂, T₃ and T₄. After the counter is cleared, the next interval begins again at T₀.

What is D₃? D₃ is the decoded instruction signal for one opcode. In this illustration D₃ is high while T₃ is high. CLR SC is a signal that clears the sequence counter. The pictured timing is one illustrative control sequence, not a rule that every instruction must finish at T₄.

Important detail: The clock provides the repeated pulses; the decoder produces the timing signals from the counter state. They are related, but T₀ is not itself the clock.

How the control unit creates the signals

The instruction register (IR) stores the instruction currently being handled. In the illustrated 16-bit basic-computer format, bit 15 is the I bit (addressing-mode indicator), bits 14–12 are a three-bit opcode, and bits 11–0 hold the address or function field, depending on the instruction type.

Step 1: The instruction arrives in IR. The opcode bits enter a 3-to-8 decoder. Three bits can encode eight combinations, so the decoder selects one of D₀ through D₇.

Step 2: The sequence counter stores a four-bit number. Four bits represent sixteen states (0 through 15). A 4-to-16 decoder selects T₀, T₁, …, T₁₅ from that number.

Step 3: Combinational control logic receives the decoded instruction D signals, timing T signals, the I bit and other status inputs. It combines them to decide which register transfers, memory operations or ALU actions are enabled.

Step 4: Normally the sequence counter increments to the next step. When an instruction is finished, a clear (CLR) signal resets SC to zero so that the next instruction begins with T₀.

Concrete example: Suppose the opcode decoder activates D₃ and the timing decoder activates T₄. A control expression such as D₃ · T₄ becomes true only when both signals are active. The control circuit can use that condition to enable a particular micro-operation. The exact operation depends on the instruction design.

What is combinational logic? It is a circuit whose outputs depend on its current inputs. The sequence counter provides the changing step number; the combinational logic decides what should happen at that step.

3. The instruction cycle: from start to finish

An instruction cycle is the complete set of steps the CPU performs to handle an instruction. A beginner-friendly model is Fetch → Decode → Execute → Write back. Some instructions also read or write data memory, and a CPU may check for interrupts between instructions.

Fetch: where is the next instruction?

The Program Counter (PC) contains the address of the next instruction. The CPU uses that address to read instruction memory. The instruction is placed in the Instruction Register (IR). In our simulator each instruction occupies one memory slot, so the PC increases by one after fetching.

Decode: what does the instruction say?

The control unit examines the opcode, which identifies the operation. For example, LOAD 5 means read data from memory address 5 into the accumulator, while ADD 6 means add the data stored at address 6.

Execute: perform the operation

The CPU reads the necessary operand and uses the ALU or data-transfer path to perform the requested operation. An operand is the value or memory location an instruction works with.

Write back: keep the answer

The result may be written into a register or memory. In our example, the Accumulator (AC) is the register that holds the working result. Not every real instruction requires a separate write-back stage.

5. Control signals and micro-operations

A micro-operation is one small register-level action performed during a control step. For example, MAR ← PC means copy the value from PC into MAR. The arrow means receives, not mathematical equality.

Why not do everything at once?

Many operations depend on earlier results. The CPU must know the address before it can read that location. It must obtain an instruction before decoding it. It must obtain operands before calculating a result. Control logic ensures that values are available when they are needed.

What happens when an interrupt occurs?

An interrupt is a request for the CPU to attend to an event, such as an input/output operation. In a simple non-pipelined explanation, after completing an instruction the CPU checks for pending permitted interrupts. If one is accepted, it saves enough state to resume later, runs an interrupt handler, then returns. The precise sequence depends on the CPU architecture.

6. Check your understanding

What does the PC contain?

The address of the next instruction to fetch.

Why does the CPU need an IR?

It holds the instruction currently being decoded or executed.

What is the difference between a clock and a control signal?

The clock provides timing. Control signals specify which action to perform.

What is MAR ← PC?

Copy the address currently in the Program Counter into the Memory Address Register.

What is the final value of memory location 7 in the example?

10, because LOAD 5 gets 7, ADD 6 adds 3, and STORE 7 writes 10.

Does every processor always have four identical instruction stages?

No. Fetch/decode/execute/write-back is a teaching model. Real architectures differ and may overlap operations through pipelining.
