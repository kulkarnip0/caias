Unit I · Memory & Storage Management

Practice Questions

This page contains 10 simple MCQs with answer explanations and 10 one-mark questions based on the Memory Management and Storage Management content covered in the Unit I presentation.

10 MCQs with Answer Explanation

1. Which of the following is a primary function of memory management?

A. Designing the CPU
B. Tracking allocated and free memory locations
C. Creating network connections
D. Formatting output devices
Answer: B. Tracking allocated and free memory locations
Memory management keeps track of every memory location and identifies whether it is allocated to a process or is currently free.

2. Memory management techniques are broadly divided into:

A. Static and dynamic
B. Primary and secondary
C. Contiguous and noncontiguous
D. Internal and external
Answer: C. Contiguous and noncontiguous
The presentation classifies memory management techniques into contiguous memory schemes and noncontiguous memory schemes.

3. Which of the following is a contiguous memory management technique?

A. Paging
B. Segmentation
C. Multiple partitioning
D. Caching
Answer: C. Multiple partitioning
Contiguous memory schemes include single contiguous allocation and multiple partitioning.

4. Which type of fragmentation is commonly associated with fixed partitioning?

A. External fragmentation
B. Internal fragmentation
C. File fragmentation
D. Disk fragmentation
Answer: B. Internal fragmentation
In fixed partitioning, a process may receive a partition larger than the memory it actually needs. The unused space inside the allocated partition is internal fragmentation.

5. Which type of fragmentation can occur in dynamic partitioning?

A. Internal fragmentation only
B. External fragmentation
C. Cache fragmentation
D. Register fragmentation
Answer: B. External fragmentation
Dynamic partitioning can leave small free gaps between allocated blocks. These scattered gaps are called external fragmentation.

6. Which of the following is a noncontiguous memory management technique?

A. Single contiguous allocation
B. Fixed partitioning
C. Paging
D. Dynamic partitioning
Answer: C. Paging
Paging and segmentation are the two noncontiguous memory schemes listed in the presentation.

7. In paging, physical memory is divided into fixed-size blocks called:

A. Segments
B. Frames
C. Files
D. Partitions
Answer: B. Frames
Paging organizes physical memory into fixed-size blocks called frames. The frames used by a process need not be contiguous.

8. Swapping means:

A. Permanently deleting a process from memory
B. Moving a process between RAM and secondary storage
C. Copying files into cache
D. Dividing a process into pages
Answer: B. Moving a process between RAM and secondary storage
Swapping temporarily moves a process from RAM to disk and brings it back into RAM when it is required again.

9. Which of the following is NOT listed as a main area of storage management?

A. File-system management
B. Mass-storage management
C. Caching
D. Process scheduling
Answer: D. Process scheduling
Storage management includes file-system management, mass-storage management, caching and I/O systems. Process scheduling belongs to process management.

10. What is the basic purpose of caching?

A. To permanently store every file
B. To copy frequently needed information into faster storage
C. To increase the number of files
D. To divide memory into partitions
Answer: B. To copy frequently needed information into faster storage
Caching temporarily stores frequently required information in a faster storage area so that future access can be quicker.

10 Simple One-Mark Questions

1. What is memory management?

Memory management is the process of controlling and coordinating computer memory and allocating memory blocks to running programs.

2. What are the two main types of memory management techniques?

Contiguous memory schemes and noncontiguous memory schemes.

3. Name the two contiguous memory management techniques.

Single contiguous allocation and multiple partitioning.

4. Name the two techniques used in multiple partitioning.

Fixed partitioning and dynamic partitioning.

5. What is internal fragmentation?

Internal fragmentation is unused memory space inside an allocated memory block.

6. What is external fragmentation?

External fragmentation occurs when free memory is divided into many small noncontiguous blocks.

7. Name the two noncontiguous memory management techniques.

Paging and segmentation.

8. What is swapping?

Swapping is temporarily moving a process from RAM to secondary storage and bringing it back when required.

9. What are the four main areas of storage management?

File-system management, mass-storage management, caching and I/O systems.

10. What are the three responsibilities of the OS in mass-storage management?

Free-space management, storage allocation and disk scheduling.
