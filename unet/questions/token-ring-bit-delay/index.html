Picture this: a bit is put onto the wire. Before the next bit can be put on the wire, the first bit has already travelled some distance. That distance is the bit length.

1. Convert data rate into time for one bit

Operation1 ÷ data rate
1 bit time = 1 / 10⁷ s = 10⁻⁷ s

2. Match the units

Propagation speed is in metres per microsecond, so convert seconds to microseconds first.
10⁻⁷ s = 0.1 μs

4. Final result

200 × 0.1 = 20 m
One-bit delay corresponds to 20 metres. Mentally: when the next bit is ready, the previous bit is about 20 m farther along the cable.
