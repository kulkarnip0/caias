Rules being checked

Rule 1 · Group only usable cells. For SOP, groups may contain 1s and helpful X cells, but never a required 0.
Rule 2 · Overlap is allowed. A required 1 may participate in more than one useful group.
Rule 3 · Group size is a power of two. Use 1, 2, 4, 8 or 16 cells as applicable.
Rule 4 · Groups must be rectangular and adjacent. No diagonal, L-shaped or disconnected groups.
Rule 5 · Make groups as large as possible. Smaller valid groups are flagged when they can be enlarged using 1/X cells.
Rule 6 · Opposite edges are adjacent. Wrap-around is valid; on a 4-variable map the four corners can form a quad.
Rule 7 · Use as few useful groups as possible. Redundant groups are reported in the final check.
