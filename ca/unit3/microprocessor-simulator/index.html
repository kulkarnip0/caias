Try the physical-control view

  1. Bus = 0101. Press and HOLD LOAD A. Observe 01, LOAD_A=1, SEL_A=0 and bus→MUX→A glowing. A must still show its old value.
  2. RELEASE LOAD A. One clock edge appears and A latches 0101.
  3. Bus = 0011. Hold LOAD B, inspect LOAD_B and bus→B, then release to latch B.
  4. Hold ADD. The controller shows 11; A→Adder, B→Adder, SUM→MUX→A glow while A itself stays unchanged. Release ADD and A latches 1000.
