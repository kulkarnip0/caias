01 · INTRODUCTION TO DIGITAL LOGIC CIRCUITS

Why do we need digital logic?

Electronic hardware works with electrical signals. To make reasoning reliable and simple, digital systems interpret those signals using two clearly separated logical states. We write those states as 0 and 1.

These symbols are not being used here as ordinary decimal numbers. They represent logical conditions. Depending on the situation, 0 and 1 may mean LOW/HIGH, OFF/ON, FALSE/TRUE, NO/YES, or inactive/active. The exact physical voltage values depend on the electronic technology, but the logical interpretation remains binary.

Electrical input→Logic 0 / 1→Logical rule→Output 0 / 1

The central idea

A digital logic circuit receives binary input conditions and produces a binary result according to a precisely defined rule. A logic gate is the simplest element that performs one such rule.

What exactly is a logic gate?

A logic gate is a basic electronic decision-making element. It accepts one or more binary inputs and produces a binary output. The output is not random and it is not decided by software; it is completely determined by the type of gate and the current input values.

For example, an AND gate asks whether all required inputs are 1. An OR gate checks whether at least one input is 1. NOT reverses a single input. XOR checks whether two inputs are different, while XNOR checks whether they are equal. NAND and NOR are inverted forms of AND and OR.

Why are only 0 and 1 enough?

Many real decisions can be reduced to two states: switch open or closed, condition satisfied or not satisfied, signal present or absent. Once these conditions are represented using 0 and 1, logical rules can be applied systematically. This is why binary representation is so powerful in digital electronics.

What is Boolean algebra?

Boolean algebra is the mathematical language used to describe logical operations. Variables such as A and B can take only two logical values, 0 or 1. Symbols then describe how those variables are combined.

For example, A·B means A AND B, while A+B means A OR B. The bar or complement symbol means NOT. These symbols should not be interpreted exactly like ordinary arithmetic. In Boolean logic, 1 + 1 = 1 because the plus sign represents OR, not decimal addition.

Why do we use truth tables?

A truth table shows the output of a logical operation for every possible input combination. This is important because a verbal statement such as “AND means both” can be misunderstood, but the truth table specifies the behaviour completely.

If there are n binary inputs, the number of possible input combinations is 2ⁿ. Therefore one input has 2 cases, two inputs have 4 cases, and three inputs have 8 cases.

How are Boolean expression, truth table and gate related?

They are three ways of describing the same logic. The gate symbol gives a visual representation, the Boolean expression gives the mathematical representation, and the truth table gives the complete input-output behaviour.

Gate symbol↔Boolean expression↔Truth table

A student should be able to move between all three. If you see Y = A·B, you should recognize AND. If you see an AND gate, you should be able to write its expression. If you see its truth table, you should be able to explain why only the 11 case produces output 1.

How should you study each gate?

For every gate, ask the same questions: What does the gate mean in words? When does its output become 1? When does it become 0? What Boolean expression represents it? What does each row of the truth table mean?

The interactive demonstrations below are designed around exactly these questions. Click the input values. The output changes immediately, and the corresponding truth-table row is highlighted so that the rule becomes visible rather than something you have to memorize.
