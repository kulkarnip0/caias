Token Ring: one-bit delay and equivalent cable length

First, understand the question

In a Token Ring network, the transmission speed is 107 bits/s and the propagation speed is 200 m/μs. The one-bit delay in this network is equivalent to what cable length?
Transmission speed107 bits every second
Propagation speed200 metres travelled every microsecond
What is the examiner really asking? A bit takes a tiny amount of time to be transmitted. During exactly that time, the signal also moves some physical distance along the ring. The question asks us to convert the time occupied by one bit into the equivalent cable distance.
A→TOKEN→B→C→D↺

A token is a special control frame that circulates around the ring. A station transmits only when it gets the token.

1Read the unit before doing any calculation

107 bits/s means the transmitter can place ten million bits on the link in one second. But the question asks about only one bit.

time for 1 bit = 1 / data rate
2Find the one-bit time
1 / 10⁷ s = 10⁻⁷ s

This is the transmission time corresponding to a single bit.

3Match the units

The propagation speed uses microseconds, so convert the one-bit time to microseconds.

10⁻⁷ s = 0.1 μs

A new bit can be placed on the link every 0.1 μs.

4Connect time with physical distance

During this 0.1 μs interval, the first bit is already propagating along the cable.

distance = propagation speed × one-bit time

Now we have everything needed for the final calculation.

5Calculate only at the final step
200 m/μs × 0.1 μs = 20 m

One-bit delay corresponds to 20 metres of cable.

In physical terms, by the time the transmitter is ready to place the next bit on the link, the previous bit has propagated about 20 m.

6Why is this useful in Token Ring?

The ring's physical length creates propagation delay. Expressing that delay in bits tells us roughly how many bits can physically occupy the ring at a given instant.

longer ring → larger propagation delay → more bit-times around the ring
