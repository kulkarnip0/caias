01 · MEMORY VS STORAGE

Memory is temporary workspace. Storage keeps information long-term.

🧠 Main Memory / RAM

RAM holds data the computer is actively using. It acts like short-term working memory and has limited capacity.

VS

💾 Storage

Hard drives and SSDs retain information for long-term storage and retrieval.

📚 Simple classroom analogy

Think of RAM as the top of your study table. You keep the books you are currently using there because they are easy to reach. The cupboard is like long-term storage: it can hold much more, but you first bring a book from the cupboard to the table when you want to work with it.

02 · WHY MEMORY MANAGEMENT MATTERS

Many applications compete for a limited amount of main memory.

Efficient memory management improves system performance by giving memory to processes that need it and releasing memory that is no longer being used. The system also keeps track of which memory locations are allocated and which are available.

Imagine a small RAM with only five regions

Some space belongs to the OS, some to applications, and some is currently free. The memory manager must continuously know the status of every region.

Main idea: RAM is finite. Good memory management prevents active programs from simply consuming memory without control.

03 · FIVE REQUIREMENTS

Memory management must support five important requirements.

1

Relocation

Programs may need to be placed or moved within memory while the system continues to manage their execution.

2

Protection

Memory use must be controlled so one program does not improperly interfere with memory used by another.

3

Sharing

The system must support controlled sharing when programs or processes need access to common information.

4

Logical organization

Memory should support the logical way programs and their components are organized.

5

Physical organization

The system must coordinate the physical memory resources that are actually available in the computer.

Together, these requirements help systems use memory efficiently and securely while supporting multitasking and modular programs.

06 · WHAT THE OS DOES

The operating system allocates, reallocates, tracks and moves memory.

The OS keeps track of the memory assigned to processes. When priorities or memory pressure change, it can move processes between main memory and storage.

🔁 Swapping

The OS can move a process away from main memory to another storage area and later bring it back when memory becomes available or the process becomes important again.

🪄 Virtual Memory

When more memory is requested than RAM can provide, virtual memory can move less-used data from RAM to a hard drive or SSD, freeing RAM for other work. This helps multitasking, although using storage in place of RAM can slow processing.

08 · MEMORY MANAGEMENT TECHNIQUES

Two broad families: contiguous and non-contiguous schemes.

Memory Management Techniques

Contiguous

TECHNIQUE 1

Single Contiguous Allocation

Main memory is divided into two broad parts: one for the OS and another for user processes. The approach is simple, but it can waste memory and is not practical for modern systems.

Operating System
User-process area
TECHNIQUE 2

Multiple Partitioning

Main memory is divided into several partitions so multiple programs can be present at the same time.

Fixed partitioning

Partitions are equal-sized. A small program may waste part of its partition, while a larger program may not fit.

Dynamic partitioning

Partitions can have different sizes and a process receives the space it needs. Over time, gaps can appear between allocated areas; this is called external fragmentation.

Non-contiguous

TECHNIQUE 1

Paging

Physical memory is organized into fixed-sized frames. A process does not need to occupy one consecutive stretch of physical memory, so its pieces can be placed into available frames.

10 · THE BIG PICTURE

Memory management is a continuous balancing act.

Track

Know which memory locations are used and which are available.

Allocate & reclaim

Give memory to processes and applications, then make it reusable when no longer needed.

Extend when necessary

Use mechanisms such as swapping and virtual memory when RAM alone cannot satisfy every active need.

Remember: Memory management is not simply “finding empty RAM.” It coordinates limited main memory across hardware, the OS and applications while supporting efficient execution, protection, sharing and multitasking.
