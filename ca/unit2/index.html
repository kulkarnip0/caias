From Latches to Flip-Flops: How a Circuit Remembers

Before learning SR, D, JK and T flip-flops, first understand the simpler idea underneath them: the SR latch. It shows how feedback can remember one bit; the clock then lets a flip-flop change that stored bit at a controlled instant.

1. WHAT is a Memory Element?

A sequential circuit needs a way to remember a previous value. The simplest memory element stores one binary bit — either 0 or 1.

The big change from combinational circuits: a latch or flip-flop has state, so its current output can depend on what happened before.

2. WHY do we need Memory?

A processor needs to remember operands, results, instruction addresses and control state between operations.

1 memory element = 1 bit→many bits = register→registers hold CPU state
Examples: a CPU register remembers data, a program counter remembers the next instruction address, and a counter remembers its previous count.

3. SR Latch — The Simplest Circuit That Remembers

An SR latch is formed from two cross-coupled gates. Each output is fed back into the opposite gate, and that feedback preserves the stored state.

Latch versus flip-flop: a basic latch responds to input levels. A flip-flop uses a clock transition so that state changes occur at a controlled instant.

What is missing? The latch can remember, but a processor needs many storage elements to update together. That is why we introduce the clock.

4. The Clock — WHEN is the Flip-Flop Allowed to Change?

A clock is a repeating digital timing signal. Edge-triggered flip-flops sample their inputs at a specified clock transition. Between relevant edges, Q remains unchanged.

6. D Flip-Flop — Store the D Input

The D flip-flop has one data input. At the active clock transition, the next state is determined directly by D.

D Flip-Flop · Graphic Symbol

Characteristic table

DQ(t+1)Operation
00Clear to 0
11Set to 1
Q(t+1) = D

Example: if D=1 when the active clock transition occurs, Q becomes 1. If D=0, Q becomes 0.

Where used? D flip-flops are natural building blocks for registers, pipeline stages and synchronizers.

7. JK Flip-Flop — SR Without the Indeterminate 1,1 Case

J and K behave like Set and Clear inputs. When both are 1, the state is complemented instead of becoming indeterminate.

JK Flip-Flop · Graphic Symbol

Characteristic table

00Q(t)No change
010Clear to 0
101Set to 1

Q(t+1) = JQ̅(t) + K̅Q(t)
Where used? The complement behavior makes JK useful in counters and other sequential circuits.

8. T Flip-Flop — The Toggle Flip-Flop

The T flip-flop is obtained from a JK type with J and K connected together. It therefore has only two input conditions.

T Flip-Flop · Graphic Symbol

Characteristic table

TQ(t+1)Operation
0Q(t)No change
1Q̅(t)Complement
Q(t+1) = Q(t) ⊕ T
Real use: counters and frequency dividers. With T=1, each active transition complements Q.

9. Excitation Tables — Work Backwards

A characteristic table specifies the next state when the inputs and present state are known. An excitation table starts with the required state transition and asks what flip-flop inputs will produce it.

11. From One Flip-Flop to a Real Computer

A. CPU Register

Four D flip-flops can store a 4-bit value such as 1011, one bit in each flip-flop.

B. Program Counter

The program counter is a register plus update logic. It retains the next instruction address from one clock cycle to the next.

C. Digital Counter

Toggle behavior lets a group of flip-flops move through binary states such as 0000, 0001, 0010 and 0011.

D. Shift Register

Connect the Q output of one D flip-flop to the D input of the next. Every active clock transition moves the stored bits by one position.

Remember the learning path: latch = feedback creates memory → flip-flop = clock-controlled memory → registers/counters = many flip-flops working together.
