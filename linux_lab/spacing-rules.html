BASH SYNTAX · SPACES MATTER

Where should I put spaces in a shell program?

Bash is not indentation-sensitive, but whitespace separates commands and arguments. Learn these few rules and most spacing mistakes in lab programs become easy to avoid.

02

The most important rule: assignment ≠ comparison

Assignment → NO spaces around =

num=10
prime=1
original=$num
reverse=0

Comparison with [ ] → spaces

if [ "$num" -eq 10 ]; then
    echo "Equal"
fi
Remember: num=10 assigns a value. [ "$num" -eq 10 ] tests a condition.
03

Arithmetic spacing

Prime, palindrome, sum-of-digits and factorial programs use arithmetic frequently.

digit=$(( num % 10 ))
reverse=$(( reverse * 10 + digit ))
num=$(( num / 10 ))
fact=$(( fact * i ))

(( num > 0 ))
(( num % i == 0 ))
(( i * i <= num ))

Spaces inside (( )) are optional. We use them because the expression is easier to read.

04

The [ ] rule

Single square brackets behave like a command, so spaces matter.

Correct ✓

[ -r "$file" ]
[ -w "$file" ]
[ -x "$file" ]
[ -f "$file" ]
[ -d "$dir" ]
[ "$a" = "$b" ]

Wrong ✗

[-r "$file"]
["$a"="$b"]
Student rule: whenever you use [ ], leave a space just inside both brackets: [ condition ].
05

if, while, for, do and done

Safe style

if (( num > 0 )); then
    echo "Positive"
fi

while (( num > 0 ))
do
    digit=$(( num % 10 ))
    num=$(( num / 10 ))
done

for ((i=1; i<=n; i++))
do
    echo "$i"
done

then, do, done and fi are separate shell keywords. Indentation does not control Bash execution; it makes the program readable.

06

Quote file names and strings

file="my data.txt"
cat "$file"
cp "$src" "$dst"

If a filename contains a space, quoting the variable keeps the whole filename as one argument. Without quotes, my data.txt can be interpreted as two arguments.

07

Pipes, redirection and background execution

Pipe |

echo "$str" | tr '[:upper:]' '[:lower:]'

The output on the left becomes input to the command on the right.

Redirection >

sort file1.txt > sorted1.txt

Writes command output to a file.

Append >>

echo "$x" >> file

Adds output to the end of a file.

Background &

sleep 10 &

& runs the command in the background.
