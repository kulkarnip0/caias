Feedforward neural network: from input values to final output

Question

A feedforward neural network receives the input values [0.5, 0.8, 0.2, 0.6]. The weights from the input layer to the hidden layer are:

W₁ = [0.1, 0.3, 0.5, 0.2]
W₂ = [0.2, 0.4, 0.6, 0.2]
W₃ = [0.3, 0.5, 0.7, 0.2]

Hidden-to-output weights are W₄ = [0.4, 0.1, 0.3] and W₅ = [0.5, 0.2, 0.4]. Find the two outputs using the sigmoid activation function, rounded to two decimals.

(a) [0.62, 0.68]   (b) [0.72, 0.78]   (c) [0.82, 0.88]   (d) [0.92, 0.98]

Assumption: the four given numbers are input values, each W₁–W₃ row connects all four inputs to one hidden neuron, W₄ and W₅ connect the three hidden neurons to two output neurons, sigmoid is applied to hidden and output neurons, and no bias terms are supplied.

1. What is a neuron?

A neuron is a small calculator. It receives numbers, multiplies each number by its connection weight, adds the results, and passes the sum through an activation function. A weight tells us how strongly one number contributes. A bias is an extra adjustable value added to the sum; this question does not provide any biases, so we take them as zero.

Imagine four taps filling three containers. Each tap contributes a different amount to each container. The three containers then feed two final containers. The arrows always go forward: this is why the network is called feedforward.

Network shape: 4 → 3 → 2. There are 4 × 3 = 12 input-to-hidden weights and 3 × 2 = 6 hidden-to-output weights: 18 weights total.

2. What is sigmoid?

Sigmoid is a function that converts any real number into a number strictly between 0 and 1:

σ(z) = 1 / (1 + e^(−z))

For example, σ(0) = 0.5. A positive input such as 0.51 produces a value above 0.5. We apply sigmoid after the weighted addition, not separately to every input, unless the question explicitly says otherwise.

3. How do we arrange the first matrix?

Write the input as a column vector with four rows. Each of W₁, W₂ and W₃ has four numbers, so place them as the three rows of a 3 × 4 matrix. Multiplying a 3 × 4 matrix by a 4 × 1 vector produces a 3 × 1 vector: one result for each hidden neuron.

W = [ 0.1 0.3 0.5 0.2 0.2 0.4 0.6 0.2 0.3 0.5 0.7 0.2 ] (3 × 4) x = [0.5, 0.8, 0.2, 0.6]ᵀ (4 × 1) z = W × x (3 × 1)

Rule: for each row of W, multiply corresponding numbers by the input column and add. The inner dimensions (4 and 4) must match.

First hidden neuron

z₁ = 0.1×0.5 + 0.3×0.8 + 0.5×0.2 + 0.2×0.6 = 0.05 + 0.24 + 0.10 + 0.12 = 0.51 h₁ = σ(0.51) = 0.624806

Second hidden neuron

z₂ = 0.2×0.5 + 0.4×0.8 + 0.6×0.2 + 0.2×0.6 = 0.10 + 0.32 + 0.12 + 0.12 = 0.66 h₂ = σ(0.66) = 0.659260

Third hidden neuron

z₃ = 0.3×0.5 + 0.5×0.8 + 0.7×0.2 + 0.2×0.6 = 0.15 + 0.40 + 0.14 + 0.12 = 0.81 h₃ = σ(0.81) = 0.692110

Keep several decimal places for intermediate calculations. Rounding too early can change the final answer.

4. Multiply hidden values by output weights

Now we have three hidden values. Each output neuron has three weights, so the second matrix has 2 rows and 3 columns.

V = [ 0.4 0.1 0.3 0.5 0.2 0.4 ] (2 × 3) h = [0.624806, 0.659260, 0.692110]ᵀ (3 × 1) u = V × h (2 × 1)

First output neuron

u₁ = 0.4×0.624806 + 0.1×0.659260 + 0.3×0.692110 = 0.523481 y₁ = σ(0.523481) = 0.627961 ≈ 0.63

Second output neuron

u₂ = 0.5×0.624806 + 0.2×0.659260 + 0.4×0.692110 = 0.721099 y₂ = σ(0.721099) = 0.672849 ≈ 0.67

Calculated result: [0.63, 0.67]

Closest listed choice: (a) [0.62, 0.68]. None of the options exactly matches the stated weights and conventional sigmoid forward pass. This may reflect a typo or a different unstated assumption in the original question.

Do not change the arithmetic to force the expected option. If the input layer itself also applies sigmoid to each of the four supplied inputs first, the result becomes approximately [0.64, 0.68], which still does not match any choice exactly.

6. Important matrix mistakes to avoid

Mistake 1: Trying to multiply 3 × 4 by 3 × 1. The inner dimensions do not match. Arrange the input as 4 × 1.

Mistake 2: Treating W₄ and W₅ as additional input-layer weights. Their three values show they connect the three hidden neurons to the two outputs.

Mistake 3: Multiplying weights but forgetting sigmoid. Weighted sums are not yet activated neuron outputs.

Mistake 4: Assuming biases that are not provided. A bias changes the output, so it must be stated or explicitly assumed.

Mistake 5: Rounding intermediate results to two decimals. Keep precision until the final step.

Quick check: what is the shape of W × x?

W is 3 × 4 and x is 4 × 1, so the answer is 3 × 1.

Quick check: why is V 2 × 3?

There are two output neurons, and each receives a connection from each of the three hidden neurons.

Quick check: what does σ(0) equal?

0.5, because 1 / (1 + e⁰) = 1 / 2.
