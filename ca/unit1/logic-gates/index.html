02 · AND GATE

Output is 1 only when every required input is 1.

Y = A · B   or   Y = AB
AND
ABY = A·BMeaning
000Neither condition is true.
010A is false, so the output remains 0.
100B is false, so the output remains 0.
111Both conditions are true, so AND becomes 1.
03 · OR GATE

Output is 1 when at least one input is 1.

Y = A + B
OR
ABY = A+BMeaning
000Neither condition is true, so OR is 0.
011B is true, so the output becomes 1.
101A is true, so the output becomes 1.
111Both are true; OR remains 1.
04 · NOT GATE

NOT reverses the input.

Y = A̅ = A′ = ¬A
NOT
AY = A̅Meaning
01Input is 0, so NOT reverses it to 1.
10Input is 1, so NOT reverses it to 0.
05 · NAND GATE

NAND = AND followed by NOT.

Y = (A·B)̅
NAND
ABYMeaning
001AND is 0, so NAND inverts it to 1.
011A is 0, so AND is 0 and NAND becomes 1.
101B is 0, so AND is 0 and NAND becomes 1.
110AND is 1, so NAND inverts it to 0.
06 · NOR GATE

NOR = OR followed by NOT.

Y = (A+B)̅
NOR
ABYMeaning
001OR is 0, so NOR inverts it to 1.
010B is 1, so OR is 1 and NOR becomes 0.
100A is 1, so OR is 1 and NOR becomes 0.
110OR is 1, so NOR remains 0 after inversion.
07 · XOR GATE

Output is 1 when the inputs are different.

Y = A ⊕ B = A̅B + AB̅
XOR
ABYMeaning
000Both inputs are the same, so XOR = 0.
011Inputs are different, so XOR = 1.
101Inputs are different, so XOR = 1.
110Both inputs are the same, so XOR = 0.
08 · XNOR GATE

Output is 1 when the inputs are equal.

Y = (A ⊕ B)̅ = AB + A̅B̅
XNOR
ABYMeaning
001Both inputs are equal, so XNOR = 1.
010Inputs are different, so XNOR = 0.
100Inputs are different, so XNOR = 0.
111Both inputs are equal, so XNOR = 1.
