06 · BOOLEAN ALGEBRA

Boolean Algebra: the mathematics of digital logic

We have already seen that logic gates operate on binary inputs and produce binary outputs. Boolean algebra gives us a mathematical language for writing, analysing and simplifying those logical operations.

Logic Gates→Boolean Expressions→Boolean Laws→Simpler Logic
01 · FIRST, WHAT IS ALGEBRA?

Why do we use algebra?

In ordinary arithmetic we work directly with known numbers. Algebra extends this idea by allowing symbols or variables such as x, y, a and b to stand for values. We then use operators and mathematical laws to form, transform and simplify expressions.

Example from ordinary algebra

x + 0 = x     and     x × 1 = x

The symbols can change, but the rule remains valid. Algebra therefore gives us a systematic way of reasoning about values without having to replace every variable with a particular number first.

Digital circuits also need a mathematical system. But unlike ordinary algebra, a digital signal is treated as having only two logical states. Therefore we use a special algebra designed for two-valued logic: Boolean algebra.

02 · WHAT IS BOOLEAN ALGEBRA?

Algebra where every variable has only two possible values

Boolean algebra is a system of mathematics based on logic. Its variables can take only one of two values: 0 or 1, commonly interpreted as false/true or LOW/HIGH. Boolean expressions describe how these variables are combined using logical operations.

For digital logic, the three fundamental operations are AND, OR and NOT. AND behaves as logical multiplication, OR as logical addition, and NOT produces the complement or inverse of a variable.

Logical operationTypical notationExampleMeaning
AND·A · B or ABLogical multiplication
OR+A + BLogical addition
NOTbar or primeA̅ or A′Complement / inversion
Important: Boolean + and · are logical operators, not ordinary arithmetic operators. For example, in Boolean algebra 1 + 1 = 1 because + means OR.

Why do we need Boolean algebra?

Boolean algebra is the mathematics used to analyse digital gates and circuits. Its laws allow a complicated Boolean expression to be rewritten in an equivalent but simpler form. A simpler expression can often be implemented using fewer logic gates, which makes the logical design easier to understand and potentially more efficient.

04 · LAWS OF BOOLEAN ALGEBRA

The rules used to simplify Boolean expressions

Annulment Law

A · 0 = 0
A + 1 = 1

AND with 0 forces the result to 0. OR with 1 forces the result to 1.

Identity Law

A + 0 = A
A · 1 = A

OR with 0 and AND with 1 leave the original variable unchanged.

Idempotent Law

A + A = A
A · A = A

Combining a Boolean variable with itself does not create a new logical state.

Complement Law

A + A̅ = 1
A · A̅ = 0

A variable and its complement must be opposite: one is always 1 while the other is 0.

Double Negation

(A̅)̅ = A

Inverting a variable twice returns the original variable.

Commutative Law

A + B = B + A
A · B = B · A

Changing the order of two terms does not change the result.

Associative Law

A + (B + C) = (A + B) + C
A(BC) = (AB)C

For repeated OR or repeated AND operations, terms can be regrouped without changing the result.

Distributive Law

A(B + C) = AB + AC
A + BC = (A+B)(A+C)

These laws allow Boolean expressions to be expanded or factored.

Absorption Law

A + AB = A
A(A+B) = A

A redundant term can be absorbed, producing a much simpler expression.

De Morgan's Theorems

(A+B)̅ = A̅B̅
(AB)̅ = A̅+B̅

When an entire OR expression is complemented it becomes an AND of the complements; when an entire AND expression is complemented it becomes an OR of the complements.

05 · HOW THE LAWS HELP US

Simplifying a Boolean expression step by step

Consider the expression:

Q = (A + B)(A + C)

Expanding and applying Boolean laws gives:

1AA + AC + AB + BCDistributive law
2A + AC + AB + BCIdempotent law: AA = A
3A(1+C) + AB + BCFactor A
4A + AB + BC1 + C = 1 and A·1 = A
5A + BCAbsorption: A + AB = A
Therefore: (A+B)(A+C) = A + BC

The expression on the right performs exactly the same Boolean function but is simpler. This is the central purpose of learning these laws: not merely to memorize formulas, but to recognise equivalent logic and reduce unnecessary operations.

From ordinary algebra to Boolean algebra
