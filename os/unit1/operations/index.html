Two modes protect the whole computer.

01 · DUAL MODE

One CPU, two levels of privilege.

The CPU works in two modes so that user programs cannot directly perform sensitive operations. User mode is restricted; kernel mode has full privileges.

👤 User Mode

The system operates in user mode when running applications such as text editors, web browsers or games.

  • Mode bit = 1
  • Restricted access to system resources
  • Cannot execute privileged instructions
  • Cannot directly access hardware
  • Uses a system call when OS help is needed

🛡️ Kernel Mode

The system enters kernel mode when the operating system needs to perform critical operations.

  • Mode bit = 0
  • Unrestricted access to system resources
  • Can execute privileged instructions
  • Can directly control hardware and critical OS functions
02 · USER MODE → SYSTEM CALL → KERNEL MODE

How does an application safely ask the OS for help?

When a user application needs a protected service such as file I/O or memory allocation, it cannot perform the operation directly. It makes a system call, which triggers a controlled transition to kernel mode.

What if a user program tries anyway?
If a user program attempts to execute a privileged instruction, the hardware generates a trap (exception) and transfers control to the operating system to handle the illegal operation.
04 · WHY DO WE NEED TWO MODES?

Privilege separation protects the system.

If every user program had kernel-level power, a faulty or malicious program could damage the operating system or interfere with other programs.

01

User Mode = Restricted

Applications can do normal work but cannot directly perform sensitive operations.

02

Kernel Mode = Privileged

The OS has the power needed to manage hardware and critical resources.

03

Result = Protection

The operating system and other programs are protected from accidental or malicious interference.

Memory trick: User mode says “I need permission.” Kernel mode says “I am allowed to perform the protected operation.”
05 · MULTIMODE OPERATION

Modern CPUs can have more than two privilege levels.

Multimode operation extends the dual-mode concept by introducing additional privilege levels to improve security and support virtualization.
