01 · DIGITAL COMPUTERS

What exactly is a digital computer?

A digital computer is a digital system that performs computational tasks. The important word here is digital. Digital means that information is represented by variables that can take only a limited number of discrete values. For example, the decimal system has ten possible digit values: 0 through 9. Each digit is one clearly separated value rather than any value in between.

This is the first idea students should understand: a digital system does not represent information as one continuously changing quantity. Instead, it works with selected, distinct states. A digital computer uses those states to represent numbers, characters, instructions and many other kinds of information.

Simple idea

Digital computer → uses discrete values. In practical electronic computers, those discrete values are normally restricted to two states, represented as 0 and 1.

Why do practical computers use binary?

Although we commonly use the decimal system in everyday life, electronic digital computers work more reliably when their components need to distinguish only two stable states. Electronic devices can be designed to recognize two clearly separated conditions much more reliably than many closely spaced conditions.

The idea also matches many logical situations naturally: yes/no, true/false, open/closed, active/inactive, present/absent. For this reason, practical digital components are normally restricted to two values, called binary values.

Digital computer→Discrete values→Two practical states→0 and 1

Bit and the binary number system

The binary number system contains only two digits: 0 and 1. A single binary digit is called a bit. One bit by itself can represent only two possibilities, but groups of bits can represent a much larger number of patterns.

Binary digits: 0 and 1   •   One binary digit = one bit

For example, with 3 bits we can form 8 different patterns, from 000 to 111. With 8 bits we can form 256 patterns. The important point is that computers combine bits into groups and then interpret those bit patterns according to an agreed meaning or code.

Groups of bits can represent many different things

A group of bits does not automatically mean only a binary number. The meaning depends on how the bits are interpreted. Bit patterns may represent binary numbers, decimal digits, alphabetic characters, machine instructions, addresses or control information.

For example, the seven-bit pattern 1001011 can be interpreted as the binary number whose decimal value is 75. But under a character code, the same pattern may represent the letter K. The physical bits are unchanged; what changes is the interpretation assigned to the pattern.

Same bits + different code or interpretation = different meaning

This is exactly why the study of binary codes is important. A computer stores patterns of 0s and 1s, and a code tells us what those patterns are meant to represent.

Hardware and software

A computer system can be viewed as having two major functional parts: hardware and software. Hardware refers to the physical electronic and electromechanical components of the computer. Software refers to the instructions and data used by the computer.

PartMeaning
HardwarePhysical electronic and electromechanical components of the computer.
SoftwareInstructions and data used by the computer.

A sequence of instructions that tells the computer what operations to perform is called a program. The information manipulated by those instructions is the data. Therefore, software provides both the instructions that control processing and the information on which those instructions operate.

System software and application software

System software is a collection of programs that helps make effective use of the computer system. The operating system is part of system software because it manages the computer's resources and provides services needed by other programs.

Application software is written to solve particular user problems or perform specific tasks. A compiler is an example of system software because it translates a program written in a high-level language into machine-language form that the computer can execute.

System software

Supports the operation and effective use of the computer. Examples include the operating system and language translators such as compilers.

Application software

Programs created to solve specific user problems or perform particular tasks.

Basic hardware parts of a digital computer

The basic hardware of a digital computer can be understood in three major parts: the CPU, memory and the input-output processor. Each has a distinct role, but they work together continuously.

1. CPU

The Central Processing Unit contains the arithmetic and logic unit, registers and control circuits. It fetches instructions, interprets them and carries out the required operations.

2. Memory

Memory stores instructions and data. Random-access memory allows the CPU to access any memory location directly in a fixed amount of access time.

3. Input-Output Processor

The input-output processor handles communication and transfer of information between the computer and the outside world.

Input / Output↔CPU↔Memory

Computer organization, computer design and computer architecture

These three terms are related, but they do not mean exactly the same thing. Understanding the distinction helps students see why a Computer Architecture course studies both the visible behaviour of a computer and the internal hardware that makes that behaviour possible.

TermMeaning
Computer organizationHow the hardware components operate and how they are connected together.
Computer designWhat hardware should be used and how the hardware parts should be connected to build the system.
Computer architectureThe structure and behaviour of the computer as seen by the user, including areas such as information formats, instruction sets and memory-addressing techniques.
Classroom summary: A digital computer performs computation using discrete values. Practical computers use two states, 0 and 1. A binary digit is a bit, and groups of bits can represent numbers, letters, instructions or control information depending on the code. A computer system consists of hardware and software, while its basic hardware includes CPU, memory and input-output facilities.
01A · HOW DIGITAL COMPUTERS LEAD TO LOGIC GATES

We know a computer uses 0 and 1 — but how does it actually make a decision with them?

A digital computer represents its information using bits, so at the hardware level the computer repeatedly receives patterns of 0s and 1s. Merely storing these bits is not enough. The computer must also operate on them: it must decide whether conditions are satisfied, combine binary inputs, invert a condition, compare two bits, and produce new binary outputs.

This is the point where logic gates enter. A logic gate is the basic hardware element that takes one or more binary inputs and applies a fixed logical rule to produce a binary output. In other words, the digital computer tells us why the machine uses 0 and 1; logic gates show us how the hardware processes those 0s and 1s.

Digital Computer→Information as Bits→0 / 1 Inputs→Logic Gate→0 / 1 Output

For example, suppose two binary inputs represent two conditions. An AND gate can check whether both conditions are true, an OR gate can check whether at least one is true, and a NOT gate can reverse a condition. Thus, logic gates are the next natural step after understanding digital computers and binary information.

Digital computer = works with binary information   →   Logic gates = perform operations on that binary information
02 · INTRODUCTION TO LOGIC GATES

Why do we need digital logic?

Electronic hardware works with electrical signals. To make reasoning reliable and simple, digital systems interpret those signals using two clearly separated logical states. We write those states as 0 and 1.

These symbols are not being used here as ordinary decimal numbers. They represent logical conditions. Depending on the situation, 0 and 1 may mean LOW/HIGH, OFF/ON, FALSE/TRUE, NO/YES, or inactive/active. The exact physical voltage values depend on the electronic technology, but the logical interpretation remains binary.

Electrical input→Logic 0 / 1→Logical rule→Output 0 / 1

The central idea

A digital logic circuit receives binary input conditions and produces a binary result according to a precisely defined rule. A logic gate is the simplest element that performs one such rule.

What exactly is a logic gate?

A logic gate is a basic electronic decision-making element. It accepts one or more binary inputs and produces a binary output. The output is not random and it is not decided by software; it is completely determined by the type of gate and the current input values.

For example, an AND gate asks whether all required inputs are 1. An OR gate checks whether at least one input is 1. NOT reverses a single input. XOR checks whether two inputs are different, while XNOR checks whether they are equal. NAND and NOR are inverted forms of AND and OR.

Why are only 0 and 1 enough?

Many real decisions can be reduced to two states: switch open or closed, condition satisfied or not satisfied, signal present or absent. Once these conditions are represented using 0 and 1, logical rules can be applied systematically. This is why binary representation is so powerful in digital electronics.

What is Boolean algebra?

Boolean algebra is the mathematical language used to describe logical operations. Variables such as A and B can take only two logical values, 0 or 1. Symbols then describe how those variables are combined.

For example, A·B means A AND B, while A+B means A OR B. The bar or complement symbol means NOT. These symbols should not be interpreted exactly like ordinary arithmetic. In Boolean logic, 1 + 1 = 1 because the plus sign represents OR, not decimal addition.

Why do we use truth tables?

A truth table shows the output of a logical operation for every possible input combination. This is important because a verbal statement such as “AND means both” can be misunderstood, but the truth table specifies the behaviour completely.

If there are n binary inputs, the number of possible input combinations is 2ⁿ. Therefore one input has 2 cases, two inputs have 4 cases, and three inputs have 8 cases.

1 input

2¹ = 2 cases
0, 1

2 inputs

2² = 4 cases
00, 01, 10, 11

3 inputs

2³ = 8 cases
000 through 111

How are Boolean expression, truth table and gate related?

They are three ways of describing the same logic. The gate symbol gives a visual representation, the Boolean expression gives the mathematical representation, and the truth table gives the complete input-output behaviour.

Gate symbol↔Boolean expression↔Truth table

A student should be able to move between all three. If you see Y = A·B, you should recognize AND. If you see an AND gate, you should be able to write its expression. If you see its truth table, you should be able to explain why only the 11 case produces output 1.

How should you study each gate?

For every gate, ask the same questions: What does the gate mean in words? When does its output become 1? When does it become 0? What Boolean expression represents it? What does each row of the truth table mean?
