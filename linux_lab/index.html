01

Install WSL from Windows PowerShell

WSL lets us use Linux command-line tools directly on Windows. We do not need to create a separate VirtualBox virtual machine for this lab.

1

Open PowerShell as Administrator

Press the Windows key and search for PowerShell. Right-click Windows PowerShell or Terminal and choose Run as administrator.

2

Install WSL

At the PowerShell prompt type:

wsl --install

This enables WSL and, on the standard installation path, installs Ubuntu as the default Linux distribution.

3

Restart Windows

When installation finishes, restart the computer if Windows asks you to do so. The required WSL components can then finish initialization.

If WSL is already installed: that is fine. In PowerShell, wsl --status shows its status and wsl -l -v lists installed Linux distributions.
02

Start Ubuntu for the first time

After WSL is installed, we need a Linux distribution. The normal wsl --install installation uses Ubuntu by default.

Open Ubuntu

Open the Windows Start menu, search for Ubuntu and launch it. You can also open PowerShell and type:

wsl

The first launch may take a little longer while Ubuntu finishes setting itself up.

Create your Linux account

On first setup, Ubuntu may ask you to create a Linux username and password. These belong to your Linux environment.

Enter new UNIX username: student
New password:
Retype new password:

Important: while typing a Linux password, the terminal normally shows no characters or stars. Type it and press Enter.

How do I know I am in Linux? The prompt will look similar to student@computer:~$. The $ prompt is where you type Linux commands.

04

Create a folder for your shell-programming work

Keeping the lab files in one directory makes them easier to find and manage.

Step A — Check where you are

pwd

You will normally start in your Linux home directory, represented by ~.

Step B — Create the folder

mkdir linux_lab

Step C — Enter it

cd linux_lab

Step D — Confirm

pwd

What just happened?

mkdir linux_labmkdir = make directory↓cd linux_labcd = change directory↓pwdprint working directory

Your prompt may now look similar to:

student@ubuntu:~/linux_lab$
05

Create your first shell script using Nano

nano is a terminal text editor. We will use it to create a very small Bash script.

1

Open a new file

nano hello.sh

If hello.sh does not exist, Nano opens an empty file with that name.

2

Type the program

#!/bin/bash

echo "Hello from Linux"
echo "My first shell script is running"
date
pwd

What is #!/bin/bash?

This first line tells the system that the script should be interpreted using the Bash shell.

What does echo do?

echo prints text to the terminal. For example, echo "Hello" displays Hello.

06

Save the file and exit Nano

This is the part beginners often forget. Writing text in Nano does not help unless the file is saved.

1

Save: Ctrl + O

Hold Ctrl and press O. Nano calls this Write Out.

Ctrl + O
2

Confirm the filename: Enter

Nano shows the filename at the bottom. Keep hello.sh and press:

Enter
3

Exit: Ctrl + X

After saving, leave Nano:

Ctrl + X
4

Check that the file exists

ls -l

You should see hello.sh in the directory.

Remember: Ctrl+O → Enter → Ctrl+X means save → confirm filename → exit.
07

Give permission and execute your script

The file now contains Bash commands. Next, make it executable and run it.

1. Give execute permission

chmod +x hello.sh

chmod changes file permissions. +x adds execute permission.

2. Run the file

./hello.sh

./ means: run the file named hello.sh from the current directory.

Expected idea

student@ubuntu:~/linux_lab$ ./hello.sh
Hello from Linux
My first shell script is running
Tue Sep 2 ...
/home/student/linux_lab

The exact date, computer name, username and path can differ on each machine.

The complete workflow to remember:
mkdir linux_lab→cd linux_lab→nano hello.sh→Ctrl+O→Enter→Ctrl+X→chmod +x hello.sh→./hello.sh
