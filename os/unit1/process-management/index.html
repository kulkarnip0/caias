01 · UNDERSTANDING PROCESS MANAGEMENT
Real life examples to understand

Process Management in OS — Restaurant Example

Think of the Operating System as a restaurant manager who manages all processes (orders) and resources. The CPU is the chef.

1. Process Creation

Customers place orders. The manager creates order cards, just as the OS creates processes and their PCBs.

2. CPU Scheduling

The manager gives the chef one order at a time.

3. Waiting / Blocked

If ingredients are missing, the order waits, like a process waiting for I/O.

4. Context Switching

The chef pauses one order and starts another; the OS saves one process state and restores another.

Key takeaway: the operating system keeps processes, CPU, memory and I/O devices coordinated efficiently.

The OS coordinates processes that compete for shared resources.

Many processes may exist at the same time and may need the same CPU, memory or I/O devices.

04 · STATE TRANSITIONS

Why does a process move?

New → ReadyOS admits it.
Ready → RunningScheduler dispatches it.
Running → WaitingIt requests I/O.
Waiting → ReadyI/O completes.
Running → ReadyIt is preempted.
Running → TerminatedIt completes.

06 · CPU-BOUND VS I/O-BOUND PROCESSES

Some processes keep the CPU busy. Others keep waiting for input and output.

A process normally alternates between CPU bursts and I/O waits. The difference is which one dominates.

🧮 CPU-Bound Process

Mostly computation: long CPU bursts and relatively infrequent I/O.

Video encodingLarge calculations3D rendering

⌨️ I/O-Bound Process

Frequent waiting for files, devices, network or user input.

Reading a fileWeb downloadKeyboard input
FeatureCPU-BoundI/O-Bound
Main activityComputationInput / output

07 · BENEFITS & DRAWBACKS

Process management makes multitasking possible—but it also creates overhead.

✓ Benefits

🖥️
Managing multiple programsSeveral applications can make progress.
⚖️
Fair resource useCPU time and memory can be shared.
🔄
Smooth switchingOS saves and restores process context.

⚠ Drawbacks

📊
OverheadTracking and scheduling processes costs CPU time and memory.
🔒
DeadlocksProcesses can become stuck waiting for one another.
⏱️
Frequent context switchingSaving/restoring state consumes CPU cycles.
