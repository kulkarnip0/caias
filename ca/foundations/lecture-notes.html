1. How Do We Calculate in BCD, Octal and Hexadecimal?

The arithmetic rule always follows the base. Decimal uses base 10, octal uses base 8, hexadecimal uses base 16, while BCD stores each decimal digit separately in four bits.

1.1 Octal arithmetic

Octal uses digits 0 to 7. When a column sum reaches 8 or more, write the base-8 remainder and carry one group of 8 to the next column. During subtraction, one borrow adds 8 to the current digit.

Example: 57₈ + 26₈ 7 + 6 = 13₁₀ = 15₈ → write 5, carry 1 5 + 2 + 1 = 8₁₀ = 10₈ → write 0, carry 1 Result = 105₈
Example: 65₈ - 27₈ 5 - 7 requires a borrow of 8 (5 + 8) - 7 = 6 5 - 1(borrow) - 2 = 2 Result = 36₈

1.2 Hexadecimal arithmetic

Hexadecimal uses 0-9 and A-F, where A=10, B=11, C=12, D=13, E=14 and F=15. A carry represents one group of 16; a borrow adds 16 to the current digit.

Example: 9A₁₆ + 2F₁₆ A + F = 10 + 15 = 25₁₀ = 19₁₆ → write 9, carry 1 9 + 2 + 1 = 12₁₀ = C₁₆ Result = C9₁₆

1.3 BCD addition and subtraction

In 8421 BCD, each decimal digit is represented by four bits. Only 0000 through 1001 are valid BCD digit patterns.

Decimal012589
BCD000000010010010110001001
Example: 5 + 7 in BCD 5 = 0101 7 = 0111 0101 + 0111 = 1100 ← invalid BCD digit Add correction 0110 1100 + 0110 = 1 0010 Result = 0001 0010 = decimal 12
BCD correction rule: after adding one BCD digit, add 0110 if the 4-bit result is greater than 1001 or if the addition produces a carry out.

BCD subtraction is commonly implemented using complement-based addition. The key idea is that hardware can reuse an adder rather than requiring a completely separate decimal subtraction circuit.

2. How Does a Computer Represent Numbers Using Codes?

2.1 Pure binary versus BCD

Pure binary represents the whole number in base 2. BCD converts each decimal digit separately to four bits.

Decimal 59 Pure binary: 59₁₀ = 111011₂ BCD: 5 → 0101, 9 → 1001 BCD(59) = 0101 1001

BCD uses more bits than pure binary but is convenient when exact decimal digits must be displayed or processed.

2.2 Decimal codes

A decimal code assigns a binary pattern to each decimal digit. 8421 BCD is a weighted decimal code because its bit positions have weights 8, 4, 2 and 1.

3. How Does a Computer Store Letters and Symbols?

ASCII

ASCII is a 7-bit character code designed for basic English letters, digits, punctuation and control characters. It defines 128 values from 0 to 127.

A = decimal 65 ASCII binary = 1000001

EBCDIC

EBCDIC is an 8-bit character encoding historically associated with IBM mainframe and midrange systems. Its byte values are arranged differently from ASCII.

Unicode

Unicode assigns code points to characters from many writing systems and symbol sets. A code point is commonly written as U+xxxx; for example, U+0041 represents A. UTF-8, UTF-16 and UTF-32 are encoding formats for storing Unicode data.

Why Unicode matters: modern systems must represent scripts such as Kannada, Hindi, Arabic and Chinese, plus symbols such as ₹ and emoji. ASCII cannot cover this range.

4. How Can a Computer Detect and Correct Data Errors?

Noise, storage faults or communication problems can change bits. Error-control codes add redundant information so a receiver can test whether a received word is valid.

4.1 Parity - error detection

With even parity, the total number of 1s including the parity bit must be even. With odd parity, the total must be odd.

Data = 1011001 Number of 1s = 4 Even-parity bit = 0

A one-bit error changes parity and is detected. Simple parity cannot identify the wrong bit and can miss some even-numbered multiple-bit errors.

4.2 Hamming distance

The Hamming distance between two binary words is the number of bit positions in which they differ. A code with minimum distance d can detect up to d-1 errors and correct up to floor((d-1)/2) errors.

4.3 Hamming-code idea

Hamming codes place parity bits at positions 1, 2, 4, 8, ... . Each parity bit checks a different subset. The pattern of failed checks forms a syndrome that identifies a single-bit error location.

If checks give P4=fail, P2=pass, P1=fail: Syndrome = 101₂ = 5 Therefore bit position 5 is the error. Flip bit 5 to correct it.

6. Why Are NAND and NOR Called Universal Gates?

A universal gate can implement NOT, AND and OR by itself. Therefore NAND alone, or NOR alone, can realize any Boolean function.

Using NAND only NOT A = A NAND A A AND B = (A NAND B) NAND (A NAND B) A OR B = (A NAND A) NAND (B NAND B)
Using NOR only NOT A = A NOR A A OR B = (A NOR B) NOR (A NOR B) A AND B = (A NOR A) NOR (B NOR B)
Exam shortcut: to prove universality, show how NOT, AND and OR are constructed using only the selected gate.

8. Can We Simplify Logic Just by Grouping 1s?

A Karnaugh map is a visual simplification method. Adjacent cells differ in only one variable because row and column labels are arranged in Gray-code order.

Grouping rules

  • For Sum-of-Products simplification, group 1s.
  • Groups must contain 1, 2, 4, 8, ... cells.
  • Make groups as large as possible.
  • Every 1 must be covered at least once.
  • Groups may overlap.
  • Opposite edges are adjacent; the map wraps around.
  • A variable disappears from a group when its value changes inside that group.
Example: F(A,B)=Σm(1,3) Cells m1 and m3 form a group of 2. A changes; B remains 1. Therefore F = B.
Best K-map habit: find the largest legal groups first. Only then write the simplified Boolean terms.

9. Quick Revision Checklist

  • Octal carry/borrow is based on 8; hexadecimal on 16.
  • BCD stores each decimal digit separately in 4 bits.
  • BCD addition uses +0110 correction for an invalid digit sum or carry.
  • ASCII is a compact English-oriented code; EBCDIC is associated with IBM systems; Unicode covers a global character repertoire.
  • Parity detects errors but does not locate the wrong bit.
  • Hamming-style parity checks can identify a single-bit error.
  • NAND and NOR are universal gates.
  • Boolean algebra simplifies algebraically; K-maps simplify visually.
  • K-map groups are powers of two and should be as large as possible.
