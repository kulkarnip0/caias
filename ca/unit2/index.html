From Latches to Flip-Flops: How a Circuit Remembers

Before learning SR, D, JK and T flip-flops, first understand the simpler idea underneath them: the SR latch. It shows how two gates and feedback can remember one bit even without a clock.

1. WHAT is a Memory Element?

A sequential circuit needs a way to remember a previous value. The simplest memory element stores one binary bit — either 0 or 1.

Input / control
What should happen?
→
Memory element
Q = 0 or 1

The big change from combinational circuits: an AND or OR gate responds only to current inputs. A latch or flip-flop has state, so its current output can depend on what happened before.

2. WHY do we need Memory?

A processor cannot be built only from AND, OR and NOT gates. It also needs to remember operands, results, instruction addresses and control state between operations.

1 memory element = 1 bit→many bits = register→registers hold CPU state
Where exactly? A CPU register remembers data, a program counter remembers the address of the next instruction, a counter remembers its previous count, and a shift register remembers bits while moving them.

3. SR Latch — The Simplest Circuit That Remembers

An SR latch is the basic starting point. It is formed from two cross-coupled logic gates. The cross-coupling means each output is fed back into the opposite gate. That feedback is what allows the circuit to preserve a state.

Latch versus flip-flop: a basic latch does not wait for a clock edge. It responds according to its input levels. A flip-flop adds clock-controlled behavior so that state changes occur at a controlled instant.
SR Latch using NAND gates

This is an active-low NAND SR latch. The bars/primes on S̅ and R̅ tell us that a LOW input performs the action.

What does every input and output mean?

S̅ — Set input
Because it is active-low, S̅ = 0 means “SET the latch.” The latch stores Q = 1.
R̅ — Reset input
Because it is active-low, R̅ = 0 means “RESET the latch.” The latch stores Q = 0.
Q — stored output
This is the bit we normally care about. Q = 1 means the latch is storing 1; Q = 0 means it is storing 0.
Q̅ — complementary output
Normally Q̅ is the opposite of Q. If Q = 1 then Q̅ = 0, and if Q = 0 then Q̅ = 1.

Truth table for the NAND SR latch

S̅R̅Q(next)Q̅(next)Meaning
11Q(previous)Q̅(previous)Hold / remember
0110SET
1001RESET
0011Forbidden / invalid

Understand the four cases slowly

Case 1 — S̅=1, R̅=1: neither input is asking for a change. Because of feedback, whatever state was already stored remains stored. This is the most important evidence that the circuit really has memory.

Case 2 — S̅=0, R̅=1: a NAND gate with any input 0 produces output 1, so the upper output is forced to Q=1. The feedback then forces Q̅=0. This is the SET state.

Case 3 — S̅=1, R̅=0: the lower NAND output is forced high, which through feedback makes Q=0 and Q̅=1. This is the RESET state.

Case 4 — S̅=0, R̅=0: both NAND outputs become 1. Then Q and Q̅ are no longer complements, so this input combination is prohibited.

Real-life way to imagine it: think of an alarm flag. A short SET action can make Q=1. Even after that action disappears, the feedback keeps Q=1. Later a RESET action clears it to Q=0.
So what is missing? The latch can remember, but it can change whenever its active input level changes. In a processor we usually want thousands or millions of storage elements to update in a coordinated way. That is why we introduce the clock and then the flip-flop.

4. The Clock — WHEN is the Flip-Flop Allowed to Change?

A clock is a repeating digital timing signal. Edge-triggered flip-flops sample their inputs at a specified clock edge. Between relevant edges, the stored Q remains unchanged.

↑ Rising edge means 0→1. ↓ Falling edge means 1→0. Think of the edge as the system saying: “Now, record the value.”

5. SR Flip-Flop — SET or RESET on a Controlled Clock Event

S = Set asks Q to become 1. R = Reset asks Q to become 0. With neither asserted, the circuit remembers its previous value. Unlike the basic latch, the flip-flop changes state only at its active clock event.

SR Flip-Flop Circuit

The clock gates the S and R inputs, while the cross-coupled gates on the right provide the storage feedback.

Connection to the latch: the cross-coupled storage idea is still there. The extra clock-controlled gates decide when the Set/Reset request is allowed to reach the storage core.

6. D Flip-Flop — “Remember THIS Bit on the Clock Edge”

The D flip-flop has one data input, D. At the active clock edge, the next Q simply becomes D.

Block Symbol
D Flip-Flop Circuit

D is split into D and its complement, so the internal Set and Reset paths are not asserted together.

Characteristic table

DQ(t+1)Action
00Store 0
11Store 1
Q(t+1) = D

Example: if D=1 at the active edge, Q becomes 1. If D later changes to 0, Q still remains 1 until the next active edge.

Where exactly? D flip-flops are the natural building blocks of registers, pipeline stages and synchronizers.

7. JK Flip-Flop — SR Without the Forbidden Case

JK keeps the Set and Reset behavior of SR, but gives the 1,1 input a useful meaning: toggle.

Block Symbol
JK Flip-Flop Circuit

Feedback from Q and Q̅ enters the input gates. When J=K=1, the next state becomes the complement of the current state.

Characteristic table

Where exactly? JK's toggle behavior is useful for counters and frequency-division logic.

8. T Flip-Flop — The Toggle Specialist

A T flip-flop has one control input. T=0: remember. T=1: toggle. It can be obtained from a JK flip-flop by tying J and K together.

Block Symbol
T Flip-Flop Circuit

T controls both feedback paths. T=0 retains the previous state; T=1 makes Q change to its opposite state.

Characteristic table

011Hold

Real use: counters and frequency dividers. With T=1, each active edge flips Q.

9. Excitation Tables — Work Backwards

A characteristic table asks: “Given the inputs and present Q, what is the next Q?” An excitation table reverses that question: “I know the state transition I want. What input must I apply?”

11. From One Flip-Flop to a Real Computer

A. CPU Register

To hold a 4-bit number such as 1011, four D flip-flops can store one bit each. At the load clock edge, all four capture their inputs together.

B. Program Counter

The program counter is a register plus update logic. It must retain the next instruction address from one clock cycle to the next.

C. Digital Counter

Toggle behavior lets a group of flip-flops represent changing binary states such as 0000, 0001, 0010 and 0011.

D. Shift Register

Connect the Q output of one D flip-flop to the D input of the next. Every clock edge moves the stored bits by one position.

Remember the learning path: SR latch = feedback creates memory → flip-flop = controlled clocked memory → registers/counters = many flip-flops working together.
