Flip-Flops: How a Circuit Remembers

Start from one simple question: how can hardware remember a 0 or 1? Then build SR, D, JK and T flip-flops from that idea, understand the clock, read characteristic tables, and finally learn excitation tables for circuit design.

1. WHAT is a Flip-Flop?

A flip-flop is a circuit that remembers one binary bit — 0 or 1 — and keeps that value until it is told to change. Formally, it is a bistable sequential logic circuit used to store one bit of information.

What should happen?
→
Flip-Flop
Q = 0 or 1

The big change from Unit I: AND/OR/NOT gates are combinational — give inputs and get an output. A flip-flop has state. It can keep its previous value until an allowed event changes it.

Most flip-flops expose two complementary outputs: Q and Q̅. If Q=1, normally Q̅=0; if Q=0, Q̅=1.

2. WHY do we need Flip-Flops?

Imagine building a processor only from AND, OR and NOT gates. It could calculate, but after the inputs disappear it would have no place to retain the result. A computer needs tiny storage elements everywhere.

1 flip-flop = 1 bit→4 flip-flops = 4-bit register→Registers hold CPU data/state
Where exactly? The program counter must remember the address of the next instruction. A CPU register must remember an operand between clock cycles. A counter must remember its previous count. A shift register must remember bits while moving them. These larger structures are built from flip-flops.

3. The Clock — WHEN is the Flip-Flop Allowed to Change?

A clock is a repeating digital timing signal. Edge-triggered flip-flops sample their inputs at a specified clock edge. Between relevant edges, the stored Q remains unchanged.

Clock:
___|‾‾‾|___|‾‾‾|___|‾‾‾|___

↑ Rising edge means 0→1. ↓ Falling edge means 1→0. Think of the edge as the teacher saying: “Now! Record the value.”

Latch vs flip-flop: a latch is generally level-sensitive; a flip-flop is generally edge-triggered. In this lesson we focus on clocked, edge-triggered flip-flop behavior.

4. SR Flip-Flop — SET or RESET a Memory Bit

S = Set asks Q to become 1. R = Reset asks Q to become 0. With neither asserted, the circuit remembers its previous value.

Block Symbol
Actual Gate Circuit — Cross-Coupled NOR Latch

The two NOR gates feed back into each other. That feedback is the key: once a state is established, the circuit can keep it even after the input pulse disappears. A clocked SR flip-flop adds clock-control gating around this storage core.

Characteristic / operation table

SRQ(t+1)Meaning
00Q(t)Hold
010Reset
101Set
11InvalidForbidden
Why can it remember? Notice the feedback wires in the gate circuit. Q influences the opposite gate, and Q̅ influences the first gate. This closed feedback path lets the previous state sustain itself.
Real-life picture: a simple alarm memory. A sensor can SET an alarm bit to 1. Even after the sensor pulse disappears, the bit remains 1. A reset control later clears it to 0.

5. D Flip-Flop — “Remember THIS Bit on the Clock Edge”

The D flip-flop removes the awkward two-input decision. It has one data input, D. At the active clock edge, the next Q simply becomes D.

Block Symbol
Gate-Level Idea — D Converted to S and R

D goes directly toward Set while its complement D̅ goes toward Reset. Therefore S and R cannot be 1 together. Practical edge-triggered D flip-flops use gated/master-slave structures so Q changes only at the clock edge.

Characteristic table

DQ(t+1)Action
00Store 0
11Store 1
Q(t+1) = D

Example: before the rising edge, D=1. At ↑, Q becomes 1. D may then change to 0, but Q remains 1 until the next active edge.

Where exactly? D flip-flops are the natural building blocks of registers. To store an 8-bit value such as 10110110, use eight D flip-flops in parallel, one per bit. They are also used in pipelines and to synchronize external digital inputs to a clocked system.

6. JK Flip-Flop — SR Without the Forbidden Case

JK keeps the useful Set and Reset behavior of SR, but gives the 1,1 input a useful meaning: toggle.

Block Symbol
Gate-Level Idea — Feedback Creates Toggle

The output is fed back to the input gating. When J=K=1, the present state decides which internal path is enabled, so the next state becomes the complement of the current state: toggle.

Characteristic table

JKQ(t+1)Action
00Q(t)Hold
010Reset
101Set
11Q̅(t)Toggle
Q(t+1) = JQ̅(t) + K̅Q(t)
Toggle means: if Q was 0, it becomes 1; if Q was 1, it becomes 0. So repeated clock edges with J=K=1 produce 0→1→0→1…
Where exactly? The toggle behavior makes JK useful for teaching and implementing binary counters and frequency division.

7. T Flip-Flop — The Toggle Specialist

A T flip-flop has one control input. T=0: remember. T=1: toggle. It can be obtained from a JK flip-flop by tying J and K together.

Block Symbol
Actual Connection — JK Used as a T Flip-Flop

One T wire drives both J and K. Therefore T=0 gives J=K=0 → hold, while T=1 gives J=K=1 → toggle. This is why T is called the toggle flip-flop.

Characteristic table

TQ(t)Q(t+1)Meaning
000Hold
011Hold
101Toggle
110Toggle
Q(t+1) = T ⊕ Q(t)
Real use: counters. With T=1, every active clock edge flips Q. If the input clock has frequency f, Q completes one full 0→1→0 cycle for every two clock periods, giving f/2. Cascaded toggle stages form binary counters and larger frequency dividers.

8. Excitation Tables — Work Backwards

A characteristic table asks: “Given the flip-flop inputs and present Q, what will the next Q be?” An excitation table reverses the problem: “I know the state transition I want. What inputs must I apply?”

Example: Present state is 0 and the circuit designer wants next state 1. For a D flip-flop, D must be 1. For a T flip-flop, T must be 1. For JK, J must be 1 while K can be either 0 or 1 — therefore K = X (don't care).

X = don't care: either 0 or 1 will produce the required transition.

10. From One Flip-Flop to a Real Computer

A. CPU Register

Suppose a processor needs to hold the 4-bit number 1011. Four D flip-flops receive D₃D₂D₁D₀ = 1011. At the load clock edge, all four store their bits together. That is the foundation of a register.

B. Program Counter

The CPU must retain “which instruction comes next?” The program counter is a register plus update logic. Its stored state survives from one clock cycle to the next because the register is made from state-holding elements.

C. Digital Counter

Toggle behavior lets flip-flops represent a changing binary state: 0000, 0001, 0010, 0011… This is used in event counters, timers and clock-division circuits.

D. Shift Register

Connect D flip-flops so that the Q of one feeds the D of the next. Each clock edge moves the stored bits by one position. This gives serial/parallel data movement.

Memory sentence for the exam: SR = Set/Reset · D = Data · JK = SR + Toggle · T = Toggle.
