04E · PARITY CODE

Error Detection Using Parity

During storage or transmission, a bit may accidentally change from 0 to 1 or from 1 to 0. A parity bit adds one redundant bit so the receiver can check whether the received pattern is consistent with the selected parity rule.

Even parity

Choose the parity bit so that the total number of 1s, including the parity bit, is even.

Data 1011001 contains four 1s → parity bit = 0 → total remains even.

Odd parity

Choose the parity bit so that the total number of 1s is odd. If the data already contains an odd number of 1s, the odd parity bit is 0. If it contains an even number, the parity bit is 1.

What parity can and cannot do

  • It is simple and requires only one extra bit.
  • It detects every single-bit error.
  • It detects any error pattern that changes the parity from even to odd or vice versa.
  • It cannot tell which particular bit is wrong.
  • It cannot correct the error by itself.
  • Some multiple-bit errors can pass unnoticed, which is why stronger codes such as Hamming code are used when correction is required.
