04B · EXCESS-3, REFLECTIVE & SEQUENTIAL PROPERTIES

Excess-3 and Important Code Properties

Excess-3

Excess-3 is a non-weighted decimal code. To encode a decimal digit, first write its 8421 BCD representation and then add 0011, which is decimal 3.

5 → BCD 0101 → +0011 → 1000

To decode, reverse the process: interpret the 4-bit pattern and subtract 3.

Self-complementing property

Excess-3 is self-complementing. If every bit of the code for a decimal digit is complemented, the resulting pattern represents the 9's complement of that digit.

1 → Excess-3 0100 → complement → 1011 → 8, and 8 = 9 − 1

Reflective / self-complementing codes

Some code families are classified by useful structural properties rather than only by weights. Aiken 2421 and Excess-3 are common examples discussed in this context.

Sequential codes

A sequential code follows the natural order of the represented decimal digits. For example, the 8421 representations for decimal digits progress from 0000 for 0 through 1001 for 9.

4:0100 → 5:0101 → 6:0110 → 7:0111 → 8:1000 → 9:1001
