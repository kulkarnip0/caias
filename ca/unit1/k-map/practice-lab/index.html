Rules being checked

Rule 1 · Group like values. For SOP, a group may contain only cells whose function value is 1.
Rule 2 · Overlap is allowed. The same 1 may appear in more than one useful group.
Rule 3 · Group size is a power of two. Valid sizes here are 1, 2, 4, 8 or 16.
Rule 4 · Groups are rectangular and adjacent. No diagonal, L-shaped or arbitrary selections.
Rule 5 · Make groups as large as possible. A legal smaller group is flagged as non-optimal when it can be enlarged using 1s.
Rule 6 · Opposite edges are adjacent. Left/right and top/bottom wrapping are legal; the four corners can form one quad.
Rule 7 · Use as few useful groups as possible. Redundant groups are reported when checking the full solution.
