Initial PCs are deliberately different: T1=0, T2=1, T3=2, T4=3.
Observe: T1 starts at PC 0, T2 at PC 1, T3 at PC 2 and T4 at PC 3. This makes it clear that each thread owns an independent program counter.

Why multithreading?

Responsiveness
One thread can wait while another continues.
Resource sharing
Threads share process memory and files.
Economy
Threads are generally cheaper than full processes.
Scalability
Kernel-schedulable threads can use multiple CPU cores.

User threads vs kernel threads

User-level threads
Managed in user space by a runtime or library.
Kernel-level threads
Known to and scheduled by the operating-system kernel.
