04C · GRAY CODE

Gray Code and Binary ↔ Gray Conversion

Gray code is a non-weighted, unit-distance code. The important property is that two consecutive code words differ in only one bit. This reduces ambiguity in applications such as position encoders, where several binary bits changing at the same instant could otherwise create a temporary wrong reading.

Binary → Gray

Rule: Copy the most significant binary bit. Every next Gray bit is obtained by XORing two adjacent Binary bits.

Binary 1011 → Gray 1110
  1. Copy first bit: 1.
  2. 1 XOR 0 = 1.
  3. 0 XOR 1 = 1.
  4. 1 XOR 1 = 0.

Remember the XOR rule: same bits give 0; different bits give 1.

Gray → Binary

Important: after copying the first Gray bit, each next Binary bit is found using the previous Binary result XOR the current Gray bit.

Gray 1110 → Binary 1011
  1. Copy first bit: B3 = 1.
  2. B2 = B3 XOR G2 = 1 XOR 1 = 0.
  3. B1 = B2 XOR G1 = 0 XOR 1 = 1.
  4. B0 = B1 XOR G0 = 1 XOR 0 = 1.
