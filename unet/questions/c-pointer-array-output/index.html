C Programming • Arrays & Pointers

Trace the pointer expression — what does the program print?

Do not guess from the options. First understand where y points, then trace the loop one iteration at a time.

Question

#include <stdio.h>
int main() {
    int x[] = {2, 4, 6, 8, 10};
    int a, b = 0, *y = x + 4;

    for (a = 0; a < 5; a++)
        b = b + (*y - a) - *(y - a);

    printf("%d", b);
    return 0;
}

Options: A) 4   B) 6   C) 8   D) 10

Build the mental model first

x[0]2
x[1]4
x[2]6
x[3]8
x[4]10

x behaves like a pointer to the first element. Therefore x + 4 points four integer positions forward, to x[4]. So y = x + 4 means y points to 10.

y → x[4] → 10
*y = 10

Important: y itself does not move inside the loop. The expression y-a temporarily looks backward from y.

Iteration 1: a = 0

b = 0 + (*y - 0) - *(y - 0)
= 0 + (10 - 0) - 10
= 0

y-0 is still x[4], whose value is 10.

Iteration 2: a = 1

y-1 points one position backward: x[3] = 8.

b = 0 + (10 - 1) - 8
= 0 + 9 - 8
= 1

Iteration 3: a = 2

y-2 → x[2] → 6.

b = 1 + (10 - 2) - 6
= 1 + 8 - 6
= 3

Iteration 4: a = 3

y-3 → x[1] → 4.

b = 3 + (10 - 3) - 4
= 3 + 7 - 4
= 6

Iteration 5: a = 4

y-4 → x[0] → 2.

b = 6 + (10 - 4) - 2
= 6 + 6 - 2
= 10

Why are the additions 0,1,2,3,4? Since the array is 2,4,6,8,10, moving one position backward reduces the pointed value by 2, while the expression also subtracts a.

(10-a) - (10-2a) = a

So b = 0+1+2+3+4 = 10.

Final answer

The program prints 10 — Option D.

Your guess was correct, but the exam-safe method is to trace y, y-a, and *(y-a) separately.

What this question is really testing

It is not mainly testing arithmetic. It tests whether you know the difference between pointer arithmetic and dereferencing: y-a changes the address being examined; *(y-a) fetches the integer stored at that address.
