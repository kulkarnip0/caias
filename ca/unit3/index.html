1. What is a CPU?

A CPU (Central Processing Unit) is the part of the computer that carries out instructions. An instruction is a small command such as load a value, add two numbers, or store a result. A program is a sequence of these instructions.

Imagine a kitchen: a recipe is a program, each recipe step is an instruction, the chef is the CPU, the pantry is memory, and the chef's small work bowls are registers. The chef needs both an order of steps and a signal for when to perform each step.

Memory

Stores instructions and data. Each location has an address, like a numbered box on a shelf.

Registers

Very small, fast storage locations inside the CPU. They hold values currently being used.

ALU

The Arithmetic Logic Unit performs operations such as addition, subtraction and comparisons.

Control unit

Directs the sequence of operations by activating the right control signals at the right time.

2. What are timing and control?

WHAT: timing

Timing means deciding when an operation happens. Computers use a clock signal that repeatedly changes between low and high levels. The clock provides a shared rhythm for many CPU activities. A clock cycle is one complete period of that repeating signal.

WHY: control

Control means deciding what happens during each step. A control signal might tell a register to load a value, tell memory to read, or tell the ALU to add. Without control, components would not know which operation to perform.

Simple example: At one step, copy the Program Counter (PC) into the Memory Address Register (MAR). At the next step, read memory. Then copy the fetched instruction into the Instruction Register (IR). The steps must occur in the correct order.

Each labelled step T₀, T₁, T₂, ... is a logical time step in our simplified teaching model. Real CPUs may use pipelining, overlapping stages, and different clocking arrangements. The simulator below deliberately shows one micro-operation at a time.

Hardwired vs microprogrammed control

Hardwired control generates control signals through fixed digital logic. It can be fast, but changing the control logic may be difficult. Microprogrammed control stores sequences of smaller control instructions in control memory. It can make complex instruction control easier to organize, though implementations differ in speed and flexibility.

3. The instruction cycle: from start to finish

An instruction cycle is the complete set of steps the CPU performs to handle an instruction. A beginner-friendly model is Fetch → Decode → Execute → Write back. Some instructions also read or write data memory, and a CPU may check for interrupts between instructions.

Fetch: where is the next instruction?

The Program Counter (PC) contains the address of the next instruction. The CPU uses that address to read instruction memory. The instruction is placed in the Instruction Register (IR). In our simulator each instruction occupies one memory slot, so the PC increases by one after fetching.

Decode: what does the instruction say?

The control unit examines the opcode, which identifies the operation. For example, LOAD 5 means read data from memory address 5 into the accumulator, while ADD 6 means add the data stored at address 6.

Execute: perform the operation

The CPU reads the necessary operand and uses the ALU or data-transfer path to perform the requested operation. An operand is the value or memory location an instruction works with.

Write back: keep the answer

The result may be written into a register or memory. In our example, the Accumulator (AC) is the register that holds the working result. Not every real instruction requires a separate write-back stage.

5. Control signals and micro-operations

A micro-operation is one small register-level action performed during a control step. For example, MAR ← PC means copy the value from PC into MAR. The arrow means receives, not mathematical equality.

Why not do everything at once?

Many operations depend on earlier results. The CPU must know the address before it can read that location. It must obtain an instruction before decoding it. It must obtain operands before calculating a result. Control logic ensures that values are available when they are needed.

What happens when an interrupt occurs?

An interrupt is a request for the CPU to attend to an event, such as an input/output operation. In a simple non-pipelined explanation, after completing an instruction the CPU checks for pending permitted interrupts. If one is accepted, it saves enough state to resume later, runs an interrupt handler, then returns. The precise sequence depends on the CPU architecture.

6. Check your understanding

What does the PC contain?

The address of the next instruction to fetch.

Why does the CPU need an IR?

It holds the instruction currently being decoded or executed.

What is the difference between a clock and a control signal?

The clock provides timing. Control signals specify which action to perform.

What is MAR ← PC?

Copy the address currently in the Program Counter into the Memory Address Register.

What is the final value of memory location 7 in the example?

10, because LOAD 5 gets 7, ADD 6 adds 3, and STORE 7 writes 10.

Does every processor always have four identical instruction stages?

No. Fetch/decode/execute/write-back is a teaching model. Real architectures differ and may overlap operations through pipelining.
