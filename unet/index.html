What does “one-bit delay is equivalent to a length” actually mean?

This lesson does not jump straight to the answer. First understand the physical meaning, then reveal the calculation one small step at a time.

First, understand the question

In a Token Ring network, the transmission speed is 107 bits/s and the propagation speed is 200 m/μs. The one-bit delay in this network is equivalent to what cable length?
Transmission speed107 bits every second
Propagation speed200 metres travelled every microsecond
Practical picture: imagine bits as tiny railway coaches moving around the ring. A new coach enters the track after every one-bit time. The question is asking: how far has the previous bit travelled by the time the next bit is put onto the cable?
A→ TOKEN→ B→ C→ D↺

The token is a special control frame that circulates around the ring. Only the station holding it gets permission to transmit.

1What does 107 bits/s tell us?

It tells us how many bits the transmitter puts onto the cable in one second. We want the time taken for only one bit.

time for 1 bit = 1 / data rate

Do not calculate the cable length yet. First find this tiny time interval.

2Find the time for one bit
1 / 10⁷ s = 10⁻⁷ s

Now convert seconds to microseconds because the propagation speed is given in metres per microsecond.

3Convert that time to microseconds

Since 1 μs = 10−6 s:

10⁻⁷ s = 0.1 μs

Meaning: the transmitter puts a new bit on the link every 0.1 μs.

4Now ask how far a bit travels in 0.1 μs

The signal travels at 200 metres in every 1 μs.

distance = propagation speed × time

So use 200 m/μs and the one-bit time of 0.1 μs.

5Only now calculate the final length
200 m/μs × 0.1 μs = 20 m

Therefore, one-bit delay is equivalent to 20 metres of cable.

Physical meaning: when one bit has moved about 20 m along the ring, the transmitter is ready to place the next bit onto the cable.

6Why does Token Ring care about this length?

The ring has a physical propagation delay. Expressing that delay in “bits” tells us how many bits can physically be present on the ring at once.

longer ring → larger propagation delay → more bits can fit on the ring

That is why a networking question converts one-bit time into an equivalent cable length.
