06 · BOOLEAN ALGEBRA

Boolean Algebra — the language used to simplify digital logic

Digital circuits work with two logical states: 0 and 1. Boolean algebra gives us a mathematical way to describe those states and the operations performed by logic gates. Instead of drawing a large circuit every time, we can write the circuit as a Boolean expression, manipulate that expression using Boolean laws, and then build an equivalent but simpler circuit.

Logic inputs 0 / 1→Boolean expression→Apply Boolean laws→Simpler expression→Simpler logic circuit
00 · BEFORE THE LAWS

What are Boolean laws?

Boolean laws are rules that tell us when one logical expression can be replaced by another without changing the output. They are similar in purpose to the rules used when simplifying ordinary algebra, but Boolean algebra operates only on logical values 0 and 1.

For example, the expression A + A·B looks as though it needs an AND operation followed by an OR operation. The Absorption Law tells us that:

A + A·B = A

Both expressions give exactly the same output for every possible value of A and B. Therefore the larger expression may be replaced by the much simpler expression A.

Why do we need the laws?

A Boolean expression obtained from a truth table or circuit may contain unnecessary terms and variables. The laws let us remove this redundancy while preserving exactly the same logical behaviour.

What does simplification achieve?

A simpler expression can require fewer gates, fewer gate inputs and fewer interconnections. The logical function remains unchanged, but its implementation becomes easier to understand and build.

How are laws connected to logic gates?

Boolean operators correspond directly to gates: · means AND, + means OR, and a complement such as A̅ means NOT. Simplifying the equation therefore simplifies the gate network.

Why prove the laws?

We should not simply assume that two expressions are equivalent. A truth table evaluates both sides for every possible input. If LHS and RHS always match, the replacement is valid.

How does Boolean algebra help a circuit?

Example:
F = A·B + A·B̅

Factor A using the distributive law:

F = A(B + B̅)

From the Complement Law, B + B̅ = 1. Therefore:

F = A·1 = A

The original expression describes two AND terms feeding an OR operation. After simplification, the entire function is simply F = A. The Boolean laws have shown that the extra logic is unnecessary.

How is this linked to Karnaugh maps?

Boolean algebra and a Karnaugh map are not unrelated topics. Both are methods for simplifying the same Boolean function. Boolean algebra performs the simplification symbolically using laws. A K-map arranges the truth-table combinations so that terms which differ in only one variable become adjacent, allowing the same simplification to be seen visually. citeturn0search0turn0search1

See the connection:
A̅B̅ + A̅B = A̅(B̅ + B) = A̅

Algebraically, B̅ + B = 1, so B disappears. In a K-map, these two minterms occupy adjacent cells because only B changes. Grouping the two cells removes B and leaves A̅. A K-map is therefore a visual way of applying the same simplification principle. citeturn0search1

How will the laws be proved?

A Boolean law states that two expressions are equivalent for every possible input. For each law below, calculate the LHS and RHS for every input combination. If the two output columns are identical in every row, the law is proved.

Write the law→List all inputs→Calculate LHS→Calculate RHS→Compare
How to read the proofs: LHS means Left-Hand Side and RHS means Right-Hand Side. The green ✓ shows that both sides produce exactly the same output.

04 · WHY THIS IS A PROOF

Every possible input has been checked

A Boolean variable can only be 0 or 1. Therefore one variable has 2 possible cases, two variables have 4 cases, and three variables have 8 cases. A truth table lists all of them. If the LHS and RHS agree in every row, there is no remaining input for which they can disagree.

1 variable → 2 rows→2 variables → 4 rows→3 variables → 8 rows
Exam method: Write the input columns first, create any required intermediate columns, calculate the LHS and RHS separately, and finally compare the last two columns. Conclude: “Since LHS = RHS for all possible input combinations, the law is proved.”
05 · USING THE LAWS

Simplifying a Boolean expression

Once the laws are established, they can be used directly during simplification. For example:

(A+B)(A+C) = A + BC
