01

Install WSL

WSL allows us to use a Linux distribution and Linux command-line tools from Windows.

1

Open PowerShell as Administrator

Press the Windows key. Type PowerShell. Right-click Windows PowerShell and choose Run as administrator. If Windows asks for permission, choose Yes.

2

Type the WSL installation command

wsl --install

Press Enter. Windows enables the components required for WSL and installs Ubuntu as the default Linux distribution.

3

Wait for installation to finish

Keep the PowerShell window open while Windows downloads and installs the required components.

4

Restart the computer

Restart Windows when the installation asks you to do so.

5

Optional: verify WSL

After restarting, open PowerShell and type:

wsl --status

To see installed Linux distributions and their WSL version, use:

wsl -l -v
If wsl --install shows help instead of installing Ubuntu: use wsl --list --online to see available distributions, then install Ubuntu with wsl --install -d Ubuntu.
02

Open Ubuntu

Now enter the Linux environment installed through WSL.

1

Launch Ubuntu

Open the Windows Start menu, search for Ubuntu, and open it. You can also open PowerShell and type:

wsl
2

Wait during the first launch

The first launch can take longer because Ubuntu is completing its initial setup.

3

Create your Linux username

Enter new UNIX username: student

You may choose another username.

4

Create your Linux password

New password:
Retype new password:

Important: Linux normally shows no stars or characters while you type the password. Type it normally and press Enter.

You are ready when you see a prompt similar to: student@computer:~$
03

Try your first Linux commands

The terminal displays the prompt. Bash reads the commands that you type after the $.

Type these one at a time

whoamiShow my Linux username
pwdShow my current directory
lsList files and directories
dateShow date and time
clearClear the screen
student@ubuntu:~$
Try: pwd, ls, whoami, date, mkdir linux_lab, cd linux_lab
student@ubuntu:~$
Remember: do not type student@ubuntu:~$. That is the prompt. Type only the command after it.
04

Create your Linux lab folder

We will keep our shell scripts together in one directory.

1

Check your current location

pwd
2

Create a directory

mkdir linux_lab

mkdir means make directory.

3

Enter the directory

cd linux_lab

cd means change directory.

4

Confirm your location

pwd

Your prompt may now look like student@ubuntu:~/linux_lab$.

05

Create a shell script with Nano

Nano is a simple text editor that runs inside the terminal.

1

Open a new file

nano hello.sh

Nano opens a file named hello.sh. If it does not exist, you are creating it now.

2

Type this program

#!/bin/bash

echo "Hello from Linux"
echo "My first shell script is running"
date
pwd

#!/bin/bash

This tells the system to interpret the script using Bash.

echo

The echo command prints text on the terminal.

06

Save and exit Nano

Use these three keystrokes in this exact order.

1

Save — Ctrl + O

Ctrl + O

In Nano this is called Write Out.

2

Confirm filename — Enter

Enter

Keep the filename hello.sh.

3

Exit — Ctrl + X

Ctrl + X
4

Check the saved file

ls -l

You should now see hello.sh.

Memory trick: Ctrl+O → Enter → Ctrl+X = Save → Confirm → Exit.
07

Execute your first shell script

First give the file execute permission, then run it.

1

Add execute permission

chmod +x hello.sh

chmod changes permissions and +x adds execute permission.

2

Run the script

./hello.sh

./ means run the file from the current directory.

3

Observe the output

Hello from Linux
My first shell script is running
...
/home/student/linux_lab

The date, username and path may be different on your computer.

Complete sequence:
wsl --install→Ubuntu→mkdir linux_lab→cd linux_lab→nano hello.sh→Ctrl+O→Enter→Ctrl+X→chmod +x hello.sh→./hello.sh
