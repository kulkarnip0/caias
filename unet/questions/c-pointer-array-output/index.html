C Programming • Arrays & Pointers

Trace the pointer expression — what does the program print?

Do not guess from the options. First build a picture of the array in memory, then follow where the pointers point.

Question

#include <stdio.h>
int main() {
    int x[] = {2, 4, 6, 8, 10};
    int a, b = 0, *y = x + 4;

    for (a = 0; a < 5; a++)
        b = b + (*y - a) - *(y - a);

    printf("%d", b);
    return 0;
}

Options: A) 4   B) 6   C) 8   D) 10

What is x?

The array name x gives the address of the first element, so think:

x → x[0] → value 2
What is x + 4?

Pointer arithmetic moves by elements, not raw bytes. So four integer positions forward lands on x[4].

x + 4 → x[4] → value 10
Very important mental model: y stays parked at x[4]. During the loop, y-a creates a temporary pointer that walks left through the array.
a = 0 : y - 0 → x[4] a = 1 : y - 1 → x[3] a = 2 : y - 2 → x[2] a = 3 : y - 3 → x[1] a = 4 : y - 4 → x[0]

*y means “read the value where y points,” so *y = 10. Likewise, *(y-a) means “move to that array cell, then read the value inside it.”

Final answer

The program prints 10 — Option D.

The safest exam method is: first draw the array, park y at x[4], then move a temporary pointer left for y-a.

One picture to remember

x ↓ [2] [4] [6] [8] [10] ↑ y As a grows: y-0 → 10 y-1 → 8 y-2 → 6 y-3 → 4 y-4 → 2

Pointer = address. Dereference (*) = value at that address. Keep those two ideas separate and this type of question becomes much easier.
