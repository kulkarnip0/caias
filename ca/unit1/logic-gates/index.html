05 · DIGITAL LOGIC CIRCUITS

Logic Gates: how computers make decisions using 0 and 1.

A logic gate is a tiny decision-making circuit. It receives one or more binary inputs, applies a logical rule, and produces a binary output. The ideas look simple—AND, OR, NOT—but these gates are the building blocks from which adders, multiplexers, registers, processors and complete digital systems are constructed.

01 · WHY DO WE NEED LOGIC GATES?

Digital circuits need a physical way to implement true/false decisions.

Computers represent information using two logical states. We usually write them as 0 and 1. In actual electronic hardware, these states correspond to two ranges of voltage. A low voltage is interpreted as logic 0, while a higher voltage is interpreted as logic 1. The exact voltage depends on the technology being used.

Once information is represented as 0 and 1, a computer must be able to perform decisions on those bits. For example: “Are both conditions true?”, “Is at least one condition true?”, “Are the two bits different?”, or “Invert this condition.” Logic gates implement these questions electronically.

0 and 1 are logical states

They do not mean ordinary decimal zero and one here. They represent states such as OFF/ON, LOW/HIGH, FALSE/TRUE or NO/YES.

Boolean algebra is the language

Boolean expressions describe the exact rule followed by the gate. Truth tables show the output for every possible input combination.

Gates become circuits

Individual gates are connected together to form larger digital circuits such as adders, comparators, encoders, decoders, multiplexers and processors.

Mental model: A logic gate is like a tiny rule box. Inputs enter on the left, the rule is applied inside, and the answer—0 or 1—appears at the output.

How many rows should a truth table have?

With n inputs, there are 2ⁿ possible input combinations. Therefore a two-input gate has 2² = 4 rows, while a three-input gate has 2³ = 8 rows.

02 · AND GATE

Output is 1 only when all required conditions are 1.

The AND gate represents the idea of “this condition AND that condition must both be true.” For a two-input AND gate, the output becomes 1 only for the combination A = 1 and B = 1.

Why use AND?

Use AND when every required condition must be satisfied. Example: a machine may start only if the power switch is ON and the safety door is closed.

When is output 0?

If even one required input is 0, the output becomes 0. That is the key property students should remember.

04 · NOT GATE / INVERTER

The NOT gate reverses the logical state.

NOT has only one input. If the input is 0, the output is 1. If the input is 1, the output is 0. For this reason it is also called an inverter.

07 · XOR / EXCLUSIVE-OR GATE

Output is 1 when the two inputs are different.

XOR is often misunderstood. It is not ordinary OR. For two inputs, XOR gives 1 when exactly one input is 1. If both inputs are equal—00 or 11—the output is 0.

09 · UNIVERSAL GATES

Why NAND and NOR are called universal.

A gate is called universal if every Boolean function can be built using only that one type of gate. NAND and NOR have this property.

Using NAND only

NOT: connect both NAND inputs together: A NAND A = A̅.

AND: NAND the inputs, then NAND the result with itself to invert it again.

OR: by De Morgan's theorem, A+B = (A̅·B̅)̅. NAND gates can create the complements and final operation.

Using NOR only

NOT: A NOR A = A̅.

OR: NOR the inputs, then NOR that output with itself.

AND: by De Morgan's theorem, AB = (A̅+B̅)̅.

This matters in hardware design because manufacturing a circuit from repeated instances of one gate type can simplify implementation and reduce design complexity.

What does the small circle or “bubble” on a gate symbol mean?

A small circle at an input or output means inversion. For example, AND with an output bubble becomes NAND; OR with an output bubble becomes NOR.

Why does Boolean OR use '+' when this is not normal addition?

In Boolean algebra the '+' symbol represents logical OR. Therefore 1 + 1 = 1 in Boolean OR, not 2. Similarly, the dot or simple adjacency in AB represents logical AND, not ordinary decimal multiplication.

11 · QUESTIONS STUDENTS COMMONLY ASK

Why, what, how and when?

Why are logic gates needed if software can make decisions?

Software decisions must eventually be executed by physical hardware. At the lowest level, transistors form logic gates, gates form circuits, and circuits execute the operations represented by machine instructions.

Are 0 and 1 actual voltages?

They are logical interpretations of voltage ranges. The exact voltage levels depend on the logic family and circuit technology.

What is the difference between OR and XOR?

OR is 1 for 01, 10 and 11. XOR is 1 only for 01 and 10. Therefore XOR means “different” for two inputs.

Why is NOT called an inverter?

Because it reverses the logical state: 0 becomes 1 and 1 becomes 0.

Why are NAND and NOR universal?

Because NOT, AND and OR can all be constructed from only NAND gates or only NOR gates. Since Boolean expressions can be built from NOT, AND and OR, any Boolean function can therefore be implemented.

Can a gate have more than two inputs?

Yes. AND, OR, NAND and NOR gates may have three or more inputs. A three-input AND outputs 1 only when all three inputs are 1.

Which gate is used in binary addition?

XOR is used to generate the sum bit, while AND contributes to carry generation in a half adder. Full adders combine these ideas for multi-bit binary addition.

Which gate checks whether two bits are equal?

XNOR. Its output is 1 for 00 and 11.

How do I quickly derive a truth table?

First list every possible input combination. Then apply the gate rule row by row. For two inputs use 00, 01, 10, 11. For three inputs use all eight combinations from 000 to 111.

What should I memorize and what should I understand?

Understand the rule first: AND = all, OR = any, NOT = opposite, XOR = different, XNOR = same. NAND and NOR are simply inverted AND and OR. Once these rules are clear, truth tables can be reconstructed instead of memorized mechanically.
