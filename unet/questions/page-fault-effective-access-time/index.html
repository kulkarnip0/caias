Effective memory access time when a page fault occurs once in 100 instructions

Question

Given memory access time as p nanoseconds and additional q nanoseconds for handling the page fault. What is the effective memory access time if a page fault occurs once for every 100 instructions?

Options: A) p + q/100    B) (p + q)/100    C) p + q    D) p/100 + q

The ten boxes are only a visual shortcut; the actual question says one fault in every 100 instructions.

1. What does p mean?

normal memory access time = p ns

For an instruction with no page fault, memory access simply takes p nanoseconds.

Kid picture: every normal cupboard trip takes p seconds. Even when nothing goes wrong, this p time is always paid.

2. What does “additional q” mean?

The word additional is very important. If a page fault happens, we still have the normal memory access cost p, and then we pay another q for handling the fault.

faulting access time = p + q
Common mistake: treating the faulting access as only q. The question says q is additional.
Kid picture: the child still made the normal cupboard trip. The store-room trip is extra. So the bad trip is not q; it is p + q.

3. What does “once for every 100 instructions” mean?

Out of 100 instructions:

99 instructions

normal access

cost = p each
1 instruction

page fault

cost = p + q

Equivalently, the page-fault probability is:

page-fault rate = 1/100 = 0.01
Think literally: if you draw 100 boxes, only one box gets the extra +q.

4. Why do we get 100p?

This is the step that makes the whole question easy.

99 normal accesses = 99p 1 faulting access = p + q

Add them:

99p + (p + q) = 99p + p + q = 100p + q
Why 100p? Because every one of the 100 instructions performs the normal memory access. The fault does not remove p; it adds q.

5. Calculate total time for 100 instructions

The 99 normal instructions cost:

99p

The one faulting instruction costs:

p + q

So total time is:

99p + (p + q) = 100p + q

6. Why do we divide by 100?

We currently know the total time for 100 instructions. But the question asks for the effective time of one typical instruction.

Imagine 100 children together spent 1,100 seconds. If you want to know the average time for one child, you divide by 100.

average = total / number of accesses EAT = (100p + q) / 100

7. Now simplify very slowly

EAT = (100p + q) / 100

Split the two parts:

EAT = 100p/100 + q/100

And:

100p/100 = p

Therefore:

EAT = p + q/100
Answer: A) p + q/100

8. Why only q gets divided by 100 in the final answer

This is the most important intuition.

So the average is simply normal cost every time + tiny share of the rare penalty.

10. Why is option B wrong?

(p + q)/100 ← WRONG

This divides the normal memory cost p by 100. But memory access happens for every instruction, not once per 100 instructions. Only the extra page-fault penalty q is spread over 100 instructions.

That is the intuition to remember: normal cost p every time + rare penalty q/100.

11. Tiny numerical example

Suppose:

p = 10 ns q = 1000 ns

99 normal accesses:

99 × 10 = 990 ns

One faulting access:

10 + 1000 = 1010 ns

Total for 100:

990 + 1010 = 2000 ns

Average:

2000 / 100 = 20 ns

Our formula gives the same:

p + q/100 = 10 + 1000/100 = 10 + 10 = 20 ns

12. One line to remember

100 accesses: 99 × p + 1 × (p + q) = 100p + q average = (100p + q)/100 = p + q/100
Final answer: (a) p + q/100.
Memory sentence: “p happens every time; q happens only once in 100.”
