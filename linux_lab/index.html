PROGRAM 1 · FOR LOOP + NESTED LOOP

Display Prime Numbers Between M and N

The program reads two limits, checks every number in that range, and prints only the prime numbers.

Program

#!/bin/bash

echo "Enter M:"
read m
echo "Enter N:"
read n

for ((num=m; num<=n; num++))
do
    if (( num < 2 )); then
        continue
    fi

    prime=1
    for ((i=2; i*i<=num; i++))
    do
        if (( num % i == 0 )); then
            prime=0
            break
        fi
    done

    if (( prime == 1 )); then
        echo -n "$num "
    fi
done

echo

What to observe

m, n
Input range
num
Current number
i
Possible divisor
prime
1 = prime, 0 = not prime
Key idea: for each num, the program starts by assuming prime=1. If any i divides it exactly, prime changes to 0 and break stops the inner loop.
