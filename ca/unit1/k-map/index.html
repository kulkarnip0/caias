01 · WHAT IS K-MAP?

A pictorial way to simplify Boolean expressions

A Karnaugh Map, or K-map, is a visual method for minimizing Boolean expressions. We place the output values into a specially arranged grid, combine adjacent cells and read the simpler expression from the variables that remain constant.

Boolean function→Put values in K-map→Make largest valid groups→Read simplified expression
Central idea: neighboring cells differ in only one variable. Inside a valid group, any variable that changes between 0 and 1 disappears. A variable that remains constant stays in the simplified term.
02 · HOW MANY CELLS?

n variables give 2ⁿ cells

Every possible input combination needs one K-map cell. Therefore a function with n variables has 2ⁿ cells.

Never form groups of 3, 5, 6 or 7 cells.

Use the largest possible groups.

For SOP group the 1s; for POS group the 0s. The same adjacency rules apply.

Complete solving strategy

Plot all 1s for SOP, or all 0s for POS.
Use X values only when they help simplify.
Search for the largest legal groups first.
Use edge wrap-around and overlap whenever useful.
Make sure every required cell is covered.
Remove redundant groups that add no necessary coverage.
For each group, keep only the variables that remain constant.
Join SOP product terms with +, or POS sum terms by multiplication.
08 · PRACTICE

Check the rules

1. Can m0 and m2 form a pair in a 3-variable map?
Yes. They are in columns BC=00 and BC=10, which are adjacent by wrap-around.
2. Can three adjacent 1s form one group?
No. Group size must be a power of two: 1, 2, 4, 8, ...
3. May an X be grouped with a 1?
Yes, if using the don't-care helps make a larger group. It may also be ignored.
4. In SOP, may a group contain a 0?
No. SOP groups cover 1s (and optional X cells), not required 0s.
5. What happens if all eight cells of a 3-variable K-map are 1?
They form one octet. A, B and C all change, so all variables disappear and F=1.
