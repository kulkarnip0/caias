01 · WHY DO WE NEED LOGIC GATES?

Digital circuits need a physical way to implement true/false decisions.

Computers represent information using two logical states, written as 0 and 1. In hardware these correspond to voltage ranges. Gates receive these states, apply a Boolean rule and produce another binary state.

0 and 1

Think OFF/ON, FALSE/TRUE, LOW/HIGH or NO/YES.

Boolean algebra

Boolean expressions describe the rule. Truth tables verify the rule for every possible input combination.

Gates become circuits

Gates combine to form adders, comparators, multiplexers, decoders, registers and processors.

How to use the demos: press A or B. A dark button means 0. A bright green button means 1. The output lamp shows the result. The correct truth-table row is highlighted automatically.

09 · UNIVERSAL GATES

Why NAND and NOR are called universal.

A universal gate can be used to construct every Boolean function.

NAND only

NOT: A NAND A = A̅.

AND: NAND the inputs, then invert that result using another NAND.

OR: use De Morgan's theorem: A+B = (A̅·B̅)̅.

NOR only

NOT: A NOR A = A̅.

OR: NOR the inputs, then invert the result.

AND: use De Morgan's theorem: AB = (A̅+B̅)̅.
