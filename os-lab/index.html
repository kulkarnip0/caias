Commands Used

Most used commands for this lab

1Ctrl + Alt + T

Open a new Terminal window in Ubuntu.

Terminal
student@ubuntu:~$ ▌
Press Ctrl + Alt + T together.
2ls

List the files and folders in the current location.

Terminal
student@ubuntu:~$ ls Desktop Documents Downloads Music Pictures
3nano prime.sh

Open or create the file prime.sh in the Nano text editor and type the shell program.

Terminal
student@ubuntu:~$ nano prime.sh GNU nano prime.sh # Type the shell program here
4bash prime.sh

Run the shell program stored in prime.sh.

Terminal
student@ubuntu:~$ bash prime.sh Enter M: 5 Enter N: 10 5 7
5Ctrl + C

Stop a command or running program when you want to interrupt it.

Terminal
student@ubuntu:~$ bash prime.sh Enter a number: ^C student@ubuntu:~$ ▌
Press Ctrl + C to interrupt the current process and return to the terminal prompt.

Lab Programs

Shell programming exercises

1

Prime Numbers Between M and N

Write a shell script to print all the prime numbers between M and N (M < N).

2

Reverse a Number and Check Palindrome

Write a shell script to reverse a given number and check whether it is a palindrome.

3

Sum of Digits

Write a shell script to find the sum of digits of a given number using loops and without using loops.

4

10 Linux Commands Using Case

Write a shell script to implement 10 Linux commands using case.

5

Files with Read, Write and Execute Permissions

Write a shell script that displays all files in the current directory for which the user has read, write and execute permissions.
