BOOLEAN FUNCTION SIMPLIFICATION

Karnaugh Map — simplify by seeing adjacency.

A K-map converts a Boolean function into a visual grid. Adjacent cells differ in only one variable, so grouping adjacent 1s lets changing variables disappear and leaves a simpler Boolean expression.

01 · START FROM BASICS

What is a Karnaugh Map?

A Karnaugh Map (K-map) is a graphical method for minimizing Boolean expressions. For n variables, the map contains 2ⁿ cells. Each cell represents one minterm.

2 variables

2² = 4 cells
2 × 2 map

3 variables

2³ = 8 cells
2 × 4 map

4 variables

2⁴ = 16 cells
4 × 4 map

Why Gray-code order?

Rows and columns use 00, 01, 11, 10, not ordinary binary order 00, 01, 10, 11. This makes neighboring cells differ in exactly one bit.

Boolean function→Place 1 / 0 / X→Make largest legal groups→Read constants→Minimized SOP
Key idea: in a group, keep only variables whose value stays constant. A variable that changes between 0 and 1 disappears from that product term.
02 · GROUPING RULES

Rules to apply every time

For a 4-variable K-map: there are 16 cells arranged as a 4 × 4 map. Rows AB and columns CD follow Gray-code order 00, 01, 11, 10. The same grouping rules apply, and valid groups may contain 1, 2, 4, 8 or 16 cells.
Rule 1 · Group like values

For SOP simplification, group 1s. Don't-care cells X may be included when they help make a larger group. X does not have to be grouped.

Rule 2 · Overlap is allowed

A 1 may belong to more than one group when overlapping creates larger or fewer useful groups.

Rule 3 · Group size is a power of 2

Legal sizes are 1, 2, 4, 8 and 16 cells. A group of 3, 5, 6 or 7 cells is invalid.

Rule 4 · Rectangles only

Groups must be horizontal or vertical rectangles. Diagonal cells are not adjacent.

Rule 5 · Make groups as large as possible

Prefer an octet over a quad, a quad over a pair, and a pair over a single cell whenever the larger group is legal.

Rule 6 · Edges wrap around

The left and right edges are adjacent; the top and bottom edges are adjacent. Therefore four corner cells can form one quad.

Rule 7 · Use as few groups as possible

Every required 1 must be covered, but unnecessary groups should be avoided.

Don't-care X

Use X as either 0 or 1 depending on which choice gives the simpler expression. Never force an X into a group if it does not help.

Remember: K-map adjacency wraps around the borders. The map behaves like a surface whose opposite edges touch.

Rule 4 · Groups must be horizontal or vertical rectangles

Horizontal and vertical adjacency is valid. Diagonal grouping, L-shapes and irregular shapes are not valid.

Rule 5 · Make each group as large as possible

If four adjacent 1s can form a quad, do not unnecessarily split them into two pairs. Larger groups eliminate more changing variables.

Rule 6 · Opposite edges and corners are adjacent

K-map borders wrap around. Left is adjacent to right, top is adjacent to bottom, and the four corner cells can form one quad.

Rule 7 · Use as few groups as possible

Cover every required 1, but avoid redundant groups. Use the fewest useful groups.

4-variable Rule 9 · Cover all required 1s with as few useful groups as possible

After making the largest groups, check that every required 1 is covered. Do not add redundant loops that do not simplify the result.

Final visual check: every 1 lies inside at least one coloured outline; every outline encloses 1, 2, 4, 8 or 16 complete cells; outlines are rectangular; wrap-around and overlap are allowed; diagonal grouping is not.
Quick grouping checklist: same values → power-of-two size → rectangle only → largest possible group → wrap around edges when useful → overlap when useful → cover all required cells using as few useful groups as possible.
