Commands Used

Most used commands for this lab

1Ctrl + Alt + T

Open a new Terminal window in Ubuntu.

Terminal
student@ubuntu:~$ ▌
Press Ctrl + Alt + T together.
2ls

List the files and folders in the current location.

Terminal
student@ubuntu:~$ ls Desktop Documents Downloads Music Pictures
3nano prime.sh

Open or create the file prime.sh in the Nano text editor and type the shell program.

Terminal
student@ubuntu:~$ nano prime.sh GNU nano prime.sh # Type the shell program here
4bash prime.sh

Run the shell program stored in prime.sh.

Terminal
student@ubuntu:~$ bash prime.sh Enter M: 5 Enter N: 10 5 7
5Ctrl + C

Stop a command or running program when you want to interrupt it.

Terminal
student@ubuntu:~$ bash prime.sh Enter a number: ^C student@ubuntu:~$ ▌
Press Ctrl + C to interrupt the current process and return to the terminal prompt.
