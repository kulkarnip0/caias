01 · WHAT IS K-MAP?

A graphical method for simplifying Boolean expressions

A Karnaugh Map, or K-map, represents a Boolean function in a grid. We fill the grid with 0s and 1s, identify legal groups, and read the reduced expression from variables that stay constant inside each group.

Boolean function→Fill K-map→Create legal groups→Minimized expression
Central idea: adjacent K-map cells differ in only one variable. When a variable changes within a group, it disappears from that group’s simplified term.
02 · HOW MANY CELLS?

n variables give 2ⁿ cells

Every possible input combination needs one cell. A function with n variables therefore requires 2ⁿ K-map cells.

Complete solving strategy

Draw the map for the correct number of variables.
Fill cells from the Boolean function.
Use X only when it helps simplify.
Look for the largest legal groups first.
Use overlap and wrap-around when useful.
Cover every required 1 for SOP.
Prefer the fewest groups that cover all required cells.
For each group, keep only the variables that remain constant.
08 · PRACTICE

Check the rules

1. Can a group contain both a required 0 and a required 1?
No. Group 1s with 1s for SOP, or 0s with 0s for POS. X may be used with either if helpful.
2. Can three adjacent 1s form one group?
No. Group size must be 1, 2, 4, 8, 16, ...
3. May two groups overlap?
Yes. Overlap is allowed when it helps form larger useful groups.
4. Can the first and last columns be grouped?
Yes. Opposite edges are adjacent because of K-map wrap-around.
5. If a quad is possible, should we normally use two pairs instead?
No. Make each group as large as possible and use as few groups as possible.
