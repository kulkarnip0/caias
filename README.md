# Computer Architecture Visual Lab

Interactive browser-based teaching visualizations for Computer Architecture.

Initial module: **How the CPU executes `ADD 2050H`** using the fetch-decode-execute cycle.

The lab uses HTML, CSS, JavaScript, and SVG animations so students can step through register transfers, buses, memory reads, decoding, ALU control, and write-back.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages

A GitHub Actions workflow in `.github/workflows/pages.yml` deploys the site to GitHub Pages on every push to `main`.
