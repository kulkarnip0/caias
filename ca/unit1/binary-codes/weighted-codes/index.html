Weighted Codes and BCD

In a weighted code, every bit position has a fixed numerical weight. The value represented by the code is found by adding the weights corresponding to the positions containing 1.

8421 BCD

The four positions have weights 8, 4, 2 and 1. Each decimal digit is encoded separately.

Decimal 5 → 4 + 1 → 0101

Example: decimal 59 is not encoded as the ordinary binary value of 59. Instead, 5 and 9 are encoded separately:

5 → 0101    9 → 1001    therefore 59 → 0101 1001

Other weighted BCD codes

Examples include 2421, 3321, 4221, 5211, 5311, 5421, 6311 and 7421. The digits in the name indicate the weights assigned to the bit positions.

Why study weighted codes?

  • They show how decimal digits can be represented directly in digital systems.
  • They are useful in displays, counters and decimal-oriented arithmetic.
  • They introduce the idea that a bit pattern can be interpreted using an agreed set of weights.
