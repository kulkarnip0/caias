Key takeaway: just like a restaurant manager keeps orders, the chef and shared resources coordinated, the operating system keeps processes, CPU, memory and I/O devices coordinated efficiently.

The OS coordinates processes that compete for shared resources.

Many processes may exist at the same time and may need the same CPU, memory or I/O devices. Process management coordinates their execution so the machine remains responsive and correct.

04 · STATE TRANSITIONS

Why does a process move?

New → ReadyThe OS admits the new process into the ready queue.
Ready → RunningThe scheduler dispatches it to the CPU.
Running → WaitingThe process requests I/O or must wait for an event.
Waiting → ReadyThe awaited event completes.
Running → ReadyThe process is preempted and returns to the ready queue.
Running → TerminatedThe process completes or is stopped.

06 · BENEFITS & LIMITATIONS

Process management helps, but it has a cost.

Benefits

  • Multiple programs can make progress.
  • CPU and memory can be shared fairly.
  • Resources are used more efficiently.

Costs / challenges

  • Tracking process information creates overhead.
  • Processes may deadlock.
  • Frequent context switching consumes CPU time.
