UNIT I · BINARY CODES · ALPHANUMERIC CODES

How does a computer store the letter “A”?

A computer ultimately works with binary patterns. Alphanumeric or character codes provide an agreed mapping between characters—letters, digits, punctuation, symbols and control characters—and numeric/binary values. This lets text entered at a keyboard be stored, processed, transmitted and displayed consistently.

Character A→Character code→Number→Binary pattern→Store / transmit→Decode→A

1. What is an alphanumeric code?

Alphanumeric codes are also called character codes. They represent alphabetic characters, decimal digits, punctuation marks, mathematical/special symbols and certain control functions in a form a digital system can process. Early computing used punched-card schemes such as Hollerith code; later systems adopted standardized codes such as ASCII, EBCDIC and Unicode.

Why do we need it?
When you press A, the computer does not store the shape of the letter as the text value. A character-encoding rule associates A with a numeric value. In ASCII, uppercase A has decimal value 65, which is binary 1000001 in 7 bits. When the value is decoded using the same convention, the character A can be displayed again.

2. ASCII

ASCII stands for American Standard Code for Information Interchange. It is a 7-bit character code based primarily on the English alphabet. Seven bits provide 2⁷ = 128 possible patterns. These include uppercase and lowercase English letters, digits, punctuation/special characters and control characters.

Step-by-step: A

1. Character: A
2. ASCII decimal value: 65
3. 65 = 64 + 1
4. 7-bit binary: 1000001
5. Decoder reads 65 and displays A.

Control characters

Not every ASCII value is a visible letter or symbol. Some values represent control functions. Examples include line feed, carriage return, horizontal tab and backspace. This made ASCII useful not only for storing text but also for communication equipment.

✓ Advantages of ASCII

  • Simple and compact 7-bit representation.
  • Standardized representation of basic English text.
  • Widely supported and historically important in computers and communication systems.
  • ASCII characters form a common subset of many modern encodings.

✕ Disadvantages of ASCII

  • Only 128 values in standard 7-bit ASCII.
  • Designed mainly around English; it cannot directly represent the full range of world writing systems.
  • Different later 8-bit extensions were not one universal standard, which could create compatibility problems.

3. EBCDIC

EBCDIC stands for Extended Binary Coded Decimal Interchange Code. It was developed by IBM as an extension/evolution of earlier Binary Coded Decimal character coding. EBCDIC uses 8 bits, giving 2⁸ = 256 possible bit patterns, and became strongly associated with IBM computer systems and peripherals.

Step-by-step example: A
In a common EBCDIC code page, uppercase A is hexadecimal C1. C1₁₆ = 1100 0001₂. Notice an important lesson: the character A does not have to use the same binary pattern in every character code. ASCII and EBCDIC are different mapping conventions.

✓ Advantages of EBCDIC

  • 8 bits allow up to 256 code values.
  • Well established in IBM mainframe environments.
  • Supports letters, digits, symbols and control information required by those systems.
  • Maintains compatibility with important legacy enterprise data and applications.

✕ Disadvantages of EBCDIC

  • Not as universally used as ASCII/Unicode in modern general-purpose interchange.
  • Its character arrangement differs from ASCII, so conversion may be required when systems exchange data.
  • Multiple EBCDIC code pages can complicate interchange.
  • It is mainly encountered today in IBM/legacy environments rather than as a universal text standard.

4. Unicode

ASCII and EBCDIC arose when computing environments were much more limited. Modern software must represent text from many languages and writing systems. Unicode addresses this by assigning characters unique code points in a very large common character repertoire.

Think beyond A–Z

A modern document may contain English, Kannada, Hindi, Greek, mathematical symbols, currency signs and many other characters. A small 7-bit character set cannot provide a unique value for all of them.

Code point vs encoding

Unicode defines character code points. Encodings such as UTF-8, UTF-16 and UTF-32 specify how those code points are represented as bytes. This distinction is useful when students later study files, networks and programming languages.

✓ Advantages of Unicode

  • Provides a common framework for characters from a very large number of languages and symbol sets.
  • Supports international and multilingual software.
  • Reduces the need for incompatible language-specific character schemes.
  • Widely adopted across modern operating systems, programming languages, web technologies and devices.

✕ Limitations / considerations

  • Unicode is more conceptually complex than a small fixed 7-bit code.
  • A character's storage size depends on the Unicode encoding used.
  • Software must correctly handle encodings, normalization and multi-byte characters.
  • Incorrect encoding assumptions can produce garbled text.
