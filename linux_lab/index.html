What exactly is Linux?

Think of Linux as the operating system environment that manages the computer's hardware and provides services to programs.

Hardware

CPU, RAM, disk, keyboard, display and network devices.

↓

Linux Kernel

The core of Linux. It manages CPU time, memory, files, devices and processes.

↓

Shell + Programs

The shell lets us give commands. Applications use operating-system services.

↓

You

You interact through graphical applications or the terminal.

Important: Linux is not “just the black terminal”. The terminal is only one way to interact with a Linux system.

03

Why is it called VirtualBox?

Because it creates a software-based virtual computer inside your real computer. The “box” is the simulated machine.

YOUR REAL COMPUTERWindows · Physical CPU · Physical RAM · Physical SSD
ORACLE VIRTUALBOXborrows some CPU, RAM and disk for a virtual machine
VIRTUAL MACHINEUbuntu thinks it has its own CPU, RAM, disk and network

Host OS

Your actual Windows installation. It controls the real hardware.

VirtualBox

The virtualization software running on Windows.

Guest OS

Ubuntu Linux running inside the virtual machine.

Why use it in a lab?

Students can experiment with Linux without replacing or repartitioning Windows.

Analogy: Windows is the apartment building. VirtualBox creates a furnished room inside it. Ubuntu lives in that room and behaves as though the room is its own computer.
04

How do I get Linux running inside Windows?

Follow these in order. The wording in VirtualBox may vary slightly by version, but the idea remains the same.

1

Install Oracle VirtualBox on Windows

Download and install VirtualBox on the Windows host machine. Accept the required networking/device-driver prompts during installation.

2

Download an Ubuntu Desktop ISO

An ISO is an image of the installation disc. Keep the .iso file somewhere easy to find, such as Downloads.

3

Create a new virtual machine

Open VirtualBox → New. Give it a name such as Ubuntu-Linux-Lab, select Linux/Ubuntu where requested, and attach the Ubuntu ISO.

4

Give the VM some resources

Allocate a reasonable portion of RAM and CPU, not all of the host resources. Create a virtual hard disk for Ubuntu.

5

Start the virtual machine

VirtualBox boots the VM from the Ubuntu ISO. Choose the normal Ubuntu installation and follow the installation screens.

6

Create your Ubuntu user account

Choose a username and password you can remember. After installation, restart the VM when requested.

7

You are now inside Linux

The Ubuntu desktop is the guest operating system. Open the Terminal application to begin the shell lab.

Lab 1 — Which numbers between M and N are prime?

A prime number has exactly two positive factors: 1 and itself. We test every candidate from M to N.

1. Create the script

nano prime.sh

2. Enter this program

#!/bin/bash

echo "Enter M:"
read m
echo "Enter N:"
read n

for ((num=m; num<=n; num++))
do
    if (( num < 2 )); then
        continue
    fi

    prime=1
    for ((i=2; i*i<=num; i++))
    do
        if (( num % i == 0 )); then
            prime=0
            break
        fi
    done

    if (( prime == 1 )); then
        echo -n "$num "
    fi
done

echo

Understand the logic

Candidate numbernum = M, M+1, ... N↓Try divisors2, 3, 4 ... up to √num↓Divides exactly?Yes → not prime
No divisor found → prime

Run it

chmod +x prime.sh
./prime.sh

Lab 2 — Can a number read the same backwards?

Reverse the number digit by digit, then compare the reversed value with the original.

Create palindrome.sh

#!/bin/bash

echo "Enter a number:"
read num

original=$num
reverse=0

while (( num > 0 ))
do
    digit=$(( num % 10 ))
    reverse=$(( reverse * 10 + digit ))
    num=$(( num / 10 ))
done

echo "Reversed number: $reverse"

if (( original == reverse )); then
    echo "$original is a palindrome"
else
    echo "$original is not a palindrome"
fi

Watch 121 reverse

121→ take last digit 112 | reverse=1→ take last digit 21 | reverse=12→ take last digit 10 | reverse=121

Run

chmod +x palindrome.sh
./palindrome.sh

Output

Enter a number:
121
Reversed number: 121
121 is a palindrome

Lab 3 — What is the sum of all digits?

Do it once with a shell loop, then again without writing an explicit shell loop.

A. Using a loop

#!/bin/bash

echo "Enter a number:"
read num

sum=0
n=$num

while (( n > 0 ))
do
    digit=$(( n % 10 ))
    sum=$(( sum + digit ))
    n=$(( n / 10 ))
done

echo "Sum of digits = $sum"

For 583: 5 + 8 + 3 = 16.

B. Without an explicit shell loop

#!/bin/bash

echo "Enter a number:"
read num

sum=$(echo "$num" | grep -o . | paste -sd+ - | bc)

echo "Sum of digits = $sum"

This forms an expression such as 5+8+3 and lets bc evaluate it. If bc is missing, install it once using sudo apt install bc.

Run both versions

nano sum_loop.sh
chmod +x sum_loop.sh
./sum_loop.sh

nano sum_no_loop.sh
chmod +x sum_no_loop.sh
./sum_no_loop.sh
